# 2 对于嵌入式UI框架，如果发生卡顿和撕裂，应当如何排查

1. 针对撕裂问题，主要考虑：
	1. 是否使用了双缓冲机制，双缓冲机制可以从根本上杜绝CPU写入缓冲区和缓冲区刷屏之间的同时执行，从而避免撕裂
	2. 此外，针对LVGL这种嵌入式框架，必须检查是否做好了上述我说过的多线程互斥问题，不然也会导致平面绘制出现脏区域等问题
2. 卡顿主要是性能问题，主要考虑：
	1. 检查中断、线程优先级，是否存在中断过多触发、线程优先级不合理的问题
	2. 可以借助RTOS自带的工具统计时间片的使用信息，查看系统负载
	3. 从硬件层面进行检查，检查是否开启了DMA2D/GPU、检查是否开启了DMA数据传输、硬件编解码器等硬件加速机制
	4. 此外，从UI/UX设计上，可以减少一些不必要的UI效果，降低帧实时预览效果(降分辨率、RGB改YUV、降帧率等)，或增加一些进度条等"安慰设计"
