Shapley算法首次于《A Value for n-Person Games》中提出，其可以用于确定某个变量对系统的贡献性。

上述[参考资料](https://zhuanlan.zhihu.com/p/654299080)中给出的例子如子章节[[SHAP贡献度分析#^s3i9ek|多人拼车问题]]所述。

## 2.1 多人拼车问题 ^s3i9ek

考虑这样一个场景，A、B、C三个人一起拼车，总计花费51块，那么问题来了，他们该如何公平分配车费呢？

AA制或许是个解决办法，但是考虑到3个人的路程不一等其他因素，AA实在有失公平性。Shapley值就是这样类似场景的一种公平的解决方案。将打车看成一场联盟(coalition)游戏，A、B、C三人共同组成一个联盟并获得一定的报酬(当然，在这个场景下报酬为负值)。

Shapeley值的解决方案从这样一个问题开始：对于随机的乘客联盟(或者说组合)来说，他们需要多少车费呢？比如A自己独自打车，需要多少钱？A和B一起拼车，又需要多少钱呢？这样所有的情况包括如下几种：

| 组合情况    | 打车费 |
| ------- | --- |
| 空集合     | 0   |
| {A}     | 15  |
| {B}     | 25  |
| {C}     | 38  |
| {A,B}   | 25  |
| {A,C}   | 41  |
| {B,C}   | 51  |
| {A,B,C} | 51  |
这些基本情况如何帮助我们进行车费分配呢？我们可以更进一步一步地计算每个乘客对每个联盟的**边际贡献**。比如，当B想打车的时候，而A已经在车上了，B的这个拼车行为会额外产生多少费用？于是我们又可以穷举所有的情况如下：

| 原有的组合 | 待加入的成员 | 原来的费用 | 当前的费用 | 待加入成员的边际贡献 |
| ----- | ------ | ----- | ----- | ---------- |
| 空集合   | A      | 0     | 15    | 15         |
| {B}   | A      | 25    | 25    | 0          |
| {C}   | A      | 38    | 41    | 3          |
| {B,C} | A      | 51    | 51    | 0          |
| 空集合   | B      | 0     | 25    | 25         |
| {A}   | B      | 15    | 25    | 10         |
| {C}   | B      | 38    | 51    | 13         |
| {A,C} | B      | 41    | 51    | 10         |
| 空集合   | C      | 0     | 38    | 38         |
| {A}   | C      | 15    | 41    | 26         |
| {B}   | C      | 25    | 51    | 26         |
| {A,B} | C      | 25    | 51    | 26         |

随后对于成员A，我们可以根据如下的方式计算权重：
1. 我们对 $\{A, B, C\}$ 列出所有可能的六种全排列：ABC、ACB、BAC、BCA、CAB、CBA
2. 对上述六种全排列计算成员A到达前的集合情况：$\phi$ 、$\phi$ 、$\{B\}$ 、$\{BC\}$ 、$\{C\}$ 、$\{CB\}$ 
然后<font color="#c00000">根据集合出现频率加权平均算出成员A的贡献度</font>：
$$
Shapley(A)=\frac{2\times 15+1\times 0+2\times 0+1\times 3}{A_3^3}=5.5
$$

## 2.2 数学定义及性质

现在给出如下数学定义：
- 玩家：$1, 2, ..., |N|$
- 所有玩家构成的联盟：$N$
- 联盟：$S$
- 联盟的大小(成员数)：$|S|$
- 价值函数：$v$
- 总价值：$v(N)$
- Shapley值：$\phi_j$
$$
\phi_j=v(j)=\sum_{S\subseteq N \setminus \{j\}} {\frac{|S|!(|N|-|S|-1)!}{|N|!} (v(S\cup{j})-v(S))}
$$
其中：
- $N \setminus \{j\}$ 表示移除了玩家 $j$ 联盟
- $S\subseteq N \setminus \{j\}$ 表示所有不包含玩家 $j$ 的联盟 $S$ 
- $\displaystyle \frac{|S|!(|N|-|S|-1)!}{|N|!}$ 为权重系数的数学表达
- $v(S\cup{j})-v(S)$ 为联盟 $S$ 包含与不包含玩家 $j$ 的价值差异

Shapley值有如下特性：
- <font color="#9bbb59">效率性</font>：所有玩家的总价值等于价值总和
- <font color="#9bbb59">对称性</font>：两个相同的玩家的贡献应当相同
- <font color="#9bbb59">无效玩家特性</font>(Dummy特性)：如果玩家 $j$ 对<u>任何联盟</u>都没有贡献，则其Shapley值等于0
- <font color="#9bbb59">可加性</font>：当贡献可以被拆分时，贡献之和等于和贡献，即
	- $(v_1+v_2)(S)=v_1(S)+v_2(S)$ 
	- $\phi_{j, v_1+v_2}=\phi_{j, v_1}+\phi_{j, v_2}$

注：
1. 上述"<u>任何联盟</u>"指由 $N$ 构成的不包含玩家 $j$ 子集，即 $S\subseteq N \setminus \{j\}$

## 3.1 基本定义

现在将Shapley套用到机器学习中，各定义之间有如下关系：

| 博弈论概念 | 机器学习概念               |           机器学习中数学符号           |
| ----- | -------------------- | :---------------------------: |
| 玩家    | 特征列                  |              $j$              |
| 联盟    | 特征列集合 $S$            |  $S\subseteq {1, 2, ..., p}$  |
| 不在联盟中 | 去掉某特征的特征集合           |      $S \setminus \{p\}$      |
| 联盟大小  | 集合中的特征数量             |            \|$S$\|            |
| 玩家数量  | 特征总数量                |              $p$              |
| 总支出   | 当前样本预测值与所有预测值的期望之差   | $f(x^{(i)})-\mathbb{E}(f(X))$ |
| 价值函数  | 模型对联盟中特征的预测值与预测值期望之差 |      $v_{f, x^{(i)}}(S)$      |
| SHAP值 | 特征 $j$ 对预测结果的贡献      |        $\phi_j^{(i)}$         |

其中：
- 价值函数 $v_{f, x^{(i)}}(S)$：
$$
v_{f, x^{(i)}}(S)=\int{f(x_S^{(i)}\cup X_C)d\mathbb{P}_{X_C}}-\mathbb{E}(f(X))
$$

经过上述定义的SHAP函数仍然满足Shapley的四大基本性质，但是上述数学定义并不能满足大多数数据需求，例如我们只有特征的数据序列而不知道分布的数学表达，则需要使用蒙特卡罗积分代替普通积分等，详见下一子章节。
