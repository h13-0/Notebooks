# 2 对于一个机械臂系统，通常如何设计其自动控制系统

考察企业：
- 网易 嵌入式 一面

1. 首先选定坐标系定义，随后输入机械臂的参数，得到每个节点的变换矩阵
2. 每乘上一个变换矩阵，就可以得到一个节点相对于其起始点的末端位置，执行连乘即可得到初始点和末端点的方程关系
3. 对于上述方程，我们可以选择解析解的数学推导，也可以选择[[自动控制/应试笔记与八股#^1sqx7f|牛顿迭代法]]等方法进行求解。前者要求较高的数学和编程能力，后者要求较高的算力。
4. 对于多自由度机械臂，通常会存在多解问题，其解空间可能是多维度的一个空间，此时我们就需要增加一些额外的约束条件，对其解空间降维，随后可以考虑路径连续性、姿态合法性等问题选出一个适合的解。
5. 随后接入对应的PID等运动系统，即可完成每个关节点的控制
