# 3 LBA和PPA是什么含义

- <font color="#9bbb59">LBA</font>：Logical Block Address，逻辑块地址
- <font color="#9bbb59">PPA</font>：Physical Page Address，物理页地址

# 4 主机反复向同一个LBA写入数据，FTL会如何处理

1. FTL采用异地更新，把新版本写入到其他的物理页，并标记其TS或版本号，更新页面映射表
2. 当访问频率过高时，可能会把对应数据搬运到SLC缓存区

# 9 为什么要ECC功能

1. NAND会出现读干扰、数据保持、漏电等问题，导致部分bit失效
2. 因此需要ECC来检查错误，并提供一定程度的纠错能力。在一些情况下可以挽救坏块中的数据
3. 且可以通过ECC中的错误计数，评估一个存储块的寿命或状态

# 11 什么是OP空间

1. OP空间是超额预留空间，SSD会保留一部分容量，用于控制器内部使用，通常用于新数据的异地写入、GC、磨损均衡或者备用块
2. 这部分区域通常不对用户开放

# 12 TRIM的作用是什么，是否意味着立即擦除，不支持TRIM会对SSD有什么影响

1. TRIM主要用于操作系统向SSD告知这些逻辑页面不再被需要，可以不再保存
2. TRIM不会意味着立即擦除，通常会在GC时才被擦除
3. 如果不使用TRIM，<font color="#c00000">文件系统依然可以通过覆盖写入的方式复用通过删除释放的空间</font>
4. <font color="#c00000">但是SSD就无法得知LBA对应的空间是否还被依赖</font>，SSD需要保存的数据会变多，<font color="#c00000">GC搬运开销增加</font>，加剧写放大
