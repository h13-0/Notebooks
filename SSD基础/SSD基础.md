# 3 FTL技术

FTL为内存转换层(Flash Translation Layer)，用于完成主机逻辑地址空间到闪存物理空间的转换。

其承担的特性有：
- 逻辑空间到物理空间的映射
- 数据的擦除和写入
- 磨损均衡：
- 读干扰问题：每个闪存块的可读取次数也是有限的
- 数据保持问题：由于电荷流失，在SSD上电时，定期扫描闪存并刷新数据
