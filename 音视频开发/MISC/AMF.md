AMF0： ^w701pn
AMF0支持如下的变量类型： ^h4qw40

| 类型             | 类型枚举   | <center>值</center>                  |
| -------------- | ------ | ----------------------------------- |
| Number         | `0x00` | IEEE 64位双精度浮点数                      |
| Boolean        | `0x01` | 1byte(8位)的bool值，仅包含 `0x00` 和 `0x01` |
| String         | `0x02` | UTF-8编码的字符串                         |
| Object         | `0x03` | key-value的pairs集合                   |
| NULL           | `0x05` |                                     |
| ECMA Array     | `0x08` |                                     |
| Object End     | `0x09` |                                     |
| Strict Array   | `0x0a` |                                     |
| Date           | `0x0b` | IEEE 64位双精度浮点数+16位时区的offset         |
| Long String    | `0x0c` |                                     |
| XML Document   | `0x0f` |                                     |
| Typed Object   | `0x10` |                                     |
| Switch to AMF3 | `0x11` |                                     |
