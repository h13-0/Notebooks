# 5.1 树的基本概念

## 5.1.1 树的定义

基本定义：
- <font color="#9bbb59">树</font>是 $n(n\geq 0)$ 个结点的有限集，且：
	- 当 $n=0$ 时，成为<font color="#9bbb59">空树</font>
	- 任何一个非空树满足：
		1. 有且仅有一个特定的称为<font color="#9bbb59">根</font>的节点
		2. 当 $n>1$ 时，其余结点可分为 $m(m>0)$ 个互不相交的有限集 $T_1, T_2, \cdots, T_m$ ，其中每个集合本身又是一棵树，并且称为根的<font color="#9bbb59">子树</font>。

明显地：
- 树的定义是递归的，且树本身就是一种递归的数据结构
- 其有如下特性：
	1. 树的根节点没有前驱，且除了根节点以外的所有节点有且仅有一个前驱
	2. 树中所有节点都可以由零个或多个后继

## 5.3.1 二叉树的遍历 ^m1hprv

### 5.3.1.1 先序、中序、后序遍历(深度优先)

<span style="background:#fff88f"><font color="#c00000">二叉树的先序、中序、后续遍历遍历中的x序是指根节点被访问的顺序</font></span>，即：
- 先序遍历访问顺序：根节点->左子树->右子树(通常为先左后右，下同)
- 中序遍历访问顺序：左子树->根节点->右子树
- 后序遍历访问顺序：左子树->右子树->根节点
通常来说，先序、中序、后序遍历都依靠递归或迭代的思想进行：

| 区别    | <center>递归</center> | <center>迭代</center> |
| ----- | ------------------- | ------------------- |
| 空间复杂度 | $O(h)$              | $O(h)$              |
| 内存位置  | 栈内存                 | 堆内存                 |
| 风险    | 深度太大会导致栈溢出          | 只要内存足够，不会溢出         |
| 额外开销  | 较大                  | 较小                  |

在性能不太敏感时，可以使用较为简单的递归写法。性能敏感时需要使用迭代写法。

#### 5.3.1.1.1 递归实现

```CPP
class Solution {
public:
    TreeNode* traverseTree(TreeNode* root) {
    	// 终止条件
        if(root == nullptr) {
            return root;
        }
		
		// 先后遍历左右子树
        traverseTree(root->left);
        traverseTree(root->right);
        // 处理根节点的顺序对应遍历顺序
		task(root)
        return root;
    }
};
```

注意点：
1. <font color="#c00000">直接使用双层循环来实现分层遍历</font>，<span style="background:#fff88f"><font color="#c00000">而非插入</font></span> `nullptr`
2. <font color="#c00000">遍历内层循环时</font>，<font color="#c00000">将</font> `.size()` <font color="#c00000">运算放置到临时变量的初始化位置</font>，避免队列的动态变化

```CPP
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
		
        // 避免访问 nullptr
        if(root == nullptr) return result;
        deque<TreeNode*> q = { root };
		
        while(!q.empty()) {
            // 使用内外两层循环，内层循环专注处理于当前层
            vector<int> current;
            // 将 q.size() 放到初始化部分，以避免 q 尺寸动态变化
            for(int i = q.size(); i > 0; i--) {
                // 取节点
                auto node = q.front();
                q.pop_front();
                // 压入结果
                current.push_back(node->val);
                // 将子节点压入队列
                if(node->left) q.push_back(node->left);
                if(node->right) q.push_back(node->right);
            }
            // 将当前层结果压入结果列表
            result.push_back(move(current));
            current.clear();
        }
        return result;
    }
};
```

## 3.2 满二叉树

定义：
- 除最后一层外，所有节点的度为2

性质：
- 高度为 $h$ 的满二叉树的节点数为：$2^{h}-1$

## 3.3 完全二叉树

定义：
- 当且仅当满二叉树的节点与该二叉树的节点编号一一对应时，称该树为完全二叉树

性质：
- 叶节点和分支节点的编号区间为：
