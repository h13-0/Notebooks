# 2 深度优先和广度优先

## 2.1 深度优先

以[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#200 岛屿数量|LeetCode 200]]为例：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#200 岛屿数量]]

本题可以看作由上下左右四个方向的二维网格构成的图结构，例如示例一中的二行二列的元素 `1` ，与其连接的四个节点分别是：
```
    1
    |
1 - 1 - 0
    |
    1
```

那么对于深度优先，其可以编写如下的递归实现：

```CPP
void dfs(vector<vector<char>>& grid, int x, int y) {
    grid[x][y] = '0';

    // 终止条件
    if(
        (x == 0 || grid[x - 1][y] == '0') &&
        (x == grid.size() - 1 || grid[x + 1][y] == '0') &&
        (y == 0 || grid[x][y - 1] == '0') &&
        (y == grid[0].size() - 1 || grid[x][y + 1] == '0')
    ) {
        return;
    }
	
	// 深度优先递归
    if(x > 0 && grid[x - 1][y] == '1') {
        dfs(grid, x - 1, y);
    }

    if(x < grid.size() - 1 && grid[x + 1][y] == '1') {
        dfs(grid, x + 1, y);
    }

    if(y > 0 && grid[x][y - 1] == '1') {
        dfs(grid, x, y - 1);
    }

    if(y < grid[0].size() - 1 && grid[x][y + 1] == '1') {
        dfs(grid, x, y + 1);
    }
}
```

不过上述的写法可以简化为：

```CPP
void dfs(vector<vector<char>>& grid, int r, int c) {
    int nr = grid.size();
    int nc = grid[0].size();

    grid[r][c] = '0';
    if (r - 1 >= 0 && grid[r-1][c] == '1') dfs(grid, r - 1, c);
    if (r + 1 < nr && grid[r+1][c] == '1') dfs(grid, r + 1, c);
    if (c - 1 >= 0 && grid[r][c-1] == '1') dfs(grid, r, c - 1);
    if (c + 1 < nc && grid[r][c+1] == '1') dfs(grid, r, c + 1);
}
```

随后遍历调用dfs即可：

```CPP
public:
    int numIslands(vector<vector<char>>& grid) {
        int nr = grid.size();
        if (!nr) return 0;
        int nc = grid[0].size();

        int num_islands = 0;
        for (int r = 0; r < nr; ++r) {
            for (int c = 0; c < nc; ++c) {
                if (grid[r][c] == '1') {
                    ++num_islands;
                    dfs(grid, r, c);
                }
            }
        }
        return num_islands;
    }
};
```

## 2.2 广度优先

尽管[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#200 岛屿数量|LeetCode 200]]也可以使用广度优先，不过这里使用[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#994 腐烂的橘子|LeetCode 994]]更合适：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#994 腐烂的橘子]]

明显地，本题需要记录层序遍历的层数，因此需要先参考[[数据结构/数据结构算法/必背算法/树和图/二叉树#2 2 2 1 迭代实现 1palzt|二叉树的层序遍历]]章节中的<font color="#c00000">层数记录方法</font>

```CPP
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        if (grid.empty() || grid[0].empty()) {
            return 0;
        }

        const int rows = grid.size();
        const int cols = grid[0].size();

        queue<pair<int, int>> q;
        int freshCount = 0;

        // 所有腐烂橘子同时作为多源 BFS 的起点
        for (int row = 0; row < rows; ++row) {
            for (int col = 0; col < cols; ++col) {
                if (grid[row][col] == 1) {
                    ++freshCount;
                } else if (grid[row][col] == 2) {
                    q.emplace(row, col);
                }
            }
        }

        // 没有新鲜橘子，不需要等待
        if (freshCount == 0) {
            return 0;
        }

        static constexpr int directions[4][2] = {
            {-1, 0},
            { 1, 0},
            { 0, -1},
            { 0, 1}
        };

        int minutes = 0;

        // 每轮处理当前时刻已经腐烂的全部橘子
        while (!q.empty() && freshCount > 0) {
            ++minutes;
            // 双层循环分层遍历
            for(int i = q.size(); i > 0; i--) {
                auto [row, col] = q.front();
                q.pop();
				
                for (const auto& direction : directions) {
                    const int nextRow = row + direction[0];
                    const int nextCol = col + direction[1];

                    if (nextRow < 0 || nextRow >= rows ||
                        nextCol < 0 || nextCol >= cols ||
                        grid[nextRow][nextCol] != 1) {
                        continue;
                    }
				
                    // 入队时立即标记，避免被其他腐烂橘子重复加入队列
                    grid[nextRow][nextCol] = 2;
                    --freshCount;
                    q.emplace(nextRow, nextCol);
                }
            }
        }

        return freshCount == 0 ? minutes : -1;
    }
};
```
