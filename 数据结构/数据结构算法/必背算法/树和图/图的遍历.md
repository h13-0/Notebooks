# 2 深度优先和广度优先

## 2.1 深度优先

以[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#200 岛屿数量|LeetCode 200]]为例：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#200 岛屿数量]]

本题可以看作由上下左右四个方向的二维网格构成的图结构，例如示例一中的二行二列的元素 `1` ，与其连接的四个节点分别是：
```
    1
    |
1 - 1 - 0
    |
    1
```

那么对于深度优先，其可以编写如下的递归实现：

```CPP
void dfs(vector<vector<char>>& grid, int x, int y) {
    grid[x][y] = '0';

    // 终止条件
    if(
        (x == 0 || grid[x - 1][y] == '0') &&
        (x == grid.size() - 1 || grid[x + 1][y] == '0') &&
        (y == 0 || grid[x][y - 1] == '0') &&
        (y == grid[0].size() - 1 || grid[x][y + 1] == '0')
    ) {
        return;
    }
	
	// 深度优先递归
    if(x > 0 && grid[x - 1][y] == '1') {
        dfs(grid, x - 1, y);
    }

    if(x < grid.size() - 1 && grid[x + 1][y] == '1') {
        dfs(grid, x + 1, y);
    }

    if(y > 0 && grid[x][y - 1] == '1') {
        dfs(grid, x, y - 1);
    }

    if(y < grid[0].size() - 1 && grid[x][y + 1] == '1') {
        dfs(grid, x, y + 1);
    }
}
```

不过上述的写法可以简化为：

```CPP
void dfs(vector<vector<char>>& grid, int r, int c) {
    int nr = grid.size();
    int nc = grid[0].size();

    grid[r][c] = '0';
    if (r - 1 >= 0 && grid[r-1][c] == '1') dfs(grid, r - 1, c);
    if (r + 1 < nr && grid[r+1][c] == '1') dfs(grid, r + 1, c);
    if (c - 1 >= 0 && grid[r][c-1] == '1') dfs(grid, r, c - 1);
    if (c + 1 < nc && grid[r][c+1] == '1') dfs(grid, r, c + 1);
}
```

随后遍历调用dfs即可：

```CPP
public:
    int numIslands(vector<vector<char>>& grid) {
        int nr = grid.size();
        if (!nr) return 0;
        int nc = grid[0].size();

        int num_islands = 0;
        for (int r = 0; r < nr; ++r) {
            for (int c = 0; c < nc; ++c) {
                if (grid[r][c] == '1') {
                    ++num_islands;
                    dfs(grid, r, c);
                }
            }
        }
        return num_islands;
    }
};
```
