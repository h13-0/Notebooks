# 2 拓扑排序

拓扑排序是针对有向无环图的一种线性排序方法，其：
- 用于解决有向无环图(DAG)中的依赖顺序问题。
- <span style="background:#fff88f"><font color="#c00000">可以用于检测图是否有环</font></span>

## 2.1 Kahn算法

其基本思路是：
0. 准备：
	1. 构造依赖图
	2. 构造入度数组，成员是每个节点的入度值
	3. 创建"<font color="#c00000">已删除的依赖</font>"<font color="#c00000">的计数器</font>
1. 找到所有入度为0的节点，并生成队列
2. 从队列中<font color="#c00000">取出</font><span style="background:#fff88f"><font color="#c00000">并删除元素</font></span>，并在图中<font color="#c00000">删除节点和依赖关系</font>
3. 删除上述依赖关系时，<font color="#c00000">要对配对点的入度</font> `--`
4. 若上述点入度归零，则加入队列
5. 重复直到队列为空

### 2.1.1 拓扑排序模板

```CPP
// n为节点数，edges为依赖边
bool topologicalSort(int n, const vector<vector<int>>& edges) {
    vector<vector<int>> graph(n);
    vector<int> indegree(n, 0);

    // 建图：u -> v, u依赖v
    for(const auto& edge : edges) {
        int u = edge[0];
        int v = edge[1];

        graph[u].push_back(v);
        indegree[v]++;
    }

    queue<int> zero_indegree;

    // 所有入度为 0 的节点入队
    for(int node = 0; node < n; node++) {
        if(indegree[node] == 0) {
            zero_indegree.push(node);
        }
    }

    int processed = 0;

    while(!zero_indegree.empty()) {
        int node = zero_indegree.front();
        zero_indegree.pop();

        processed++;

        // 删除 node 发出的所有边
        for(int next : graph[node]) {
            indegree[next]--;

            if(indegree[next] == 0) {
                zero_indegree.push(next);
            }
        }
    }

    // 全部节点都能被删除，则不存在环
    return processed == n;
}
```
