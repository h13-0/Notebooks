# 2 贪心概述

贪心算法的核心思路为：
- 通过找到每一步的最优解，从而在逐步搜索中找到全局的最优解

# 3 贪心实例

## 3.1 买卖股票的最佳时机

[[../../LeetCode/LeetCode题目汇总#121 买卖股票的最佳时机|LeetCode 121]]：
![[../../LeetCode/LeetCode题目汇总#121 买卖股票的最佳时机]]

根据贪心原理：
1. 从前向后遍历每一天
2. 维护截止到<font color="#c00000">该天能买入的最低价格</font>、<font color="#c00000">该天及之前卖出所能达到的最大收益</font>：
	1. $最低价格=min(当日价格, 最低价格)$
	2. $最大收益=max(最大收益, 当日价格-最低价格)$
3. 遍历至最后一天时最大收益即为所求

```CPP
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int min_price = prices[0];
        int max_profit = 0;
        for(const auto& price : prices) {
            min_price = min(min_price, price);
            max_profit = max(max_profit, price - min_price);
        }
        return max_profit;
    }
};
```

## 3.2 跳跃游戏

[[../../LeetCode/LeetCode题目汇总#55 跳跃游戏|LeetCode 55]]：
![[../../LeetCode/LeetCode题目汇总#55 跳跃游戏]]

思路：
- 从前向后遍历，每一步关注于最远能走多远即可
- 遍历当前步时，需要检查能否抵达当前步

```CPP
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int right_most = nums[0];
		
        for(int i = 0; i < nums.size(); i++) {
            if(right_most < i) return false;
            right_most = max(right_most, nums[i] + i);
        }
        return right_most >= nums.size() - 1;
    }
};
```
