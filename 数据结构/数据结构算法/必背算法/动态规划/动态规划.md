# 2 动态规划概述

动态规划，`Dynamic Programming`，简称<font color="#9bbb59">DP</font>，是一种通过把原问题分解为相对简单的子问题的方式求解复杂问题的方法。
其核心特性为：
- 大事化小
- 记忆结果
- 不再重复

动态规划可以解决的问题通常具备如下特征：
1. 重叠子问题：求解过程中，遇到了很多个重复的小问题
	- 例如：求解斐波那契数列 $F(n)=F(n-1)+F(n-2), F(0)=0, F(1)=1$ 
	- 那么：在求解的过程中，将重复 $n-k$ 次求解 $F(k)$ 
2. 最优子结构：原问题的最优解可以通过子问题的最优解推导出来。
	- 例如：求从北京坐火车去深圳的最短时间
	- 假设我们已知从北京去深圳必经过武汉，那么：
		- "北京->深圳的最短时间"="北京->武汉的最短时间"+"武汉->深圳的最短时间"

动态规划问题在求解时有如下的三部曲：
1. <span style="background:#fff88f"><font color="#c00000">定义状态</font></span>：定义数组，并明确数组中元素的含义
	- 以斐波那契数列为例，数组 `dp[n]` 就表示斐波那契数列中第 `n` 的元素的值
	- 以[[动态规划#^5o8m54|爬楼梯]]为例，数组 `dp[n]` 就表示爬到第 `n` 个台阶的方法数量
2. <span style="background:#fff88f"><font color="#c00000">定义状态转移方程</font></span>：<font color="#c00000">找到</font> `dp[i]` <font color="#c00000">和之前状态之间的联系</font>
	- 以斐波那契数列为例，状态转移方程即为其定义 $F(n)=F(n-1)+F(n-2)$ 
	- 以[[动态规划#^5o8m54|爬楼梯]]为例，其状态转移方程也为 $F(n)=F(n-1)+F(n-2)$ 
3. <span style="background:#fff88f"><font color="#c00000">初始化</font></span>：为最基础最简单的情况进行求解和赋值(需要满足状态转移方程的启动条件)
	- 以斐波那契数列为例，初始值即为 $F(0)=0, F(1)=1$ 
	- 以[[动态规划#^5o8m54|爬楼梯]]为例，<font color="#c00000">其初始值为</font> $F(1)=1, F(2)=2$

## 3.2 爬楼梯 ^5o8m54

[[../../LeetCode/LeetCode题目汇总#70 爬楼梯|LeetCode 70]]：
![[../../LeetCode/LeetCode题目汇总#70 爬楼梯]]

经过动态规划三部曲的分析，不难得出爬楼梯问题类似于求斐波那契数列，只是初始值不一样，其值也与斐波那契数列之间有一个错位。

```CPP
class Solution {
public:
    int climbStairs(int n) {
        // 定义数组 methods[n] , methods[i] 为 i+1 个台阶时的方法数量
        // 初始化 methods[0] = 1, methods[1] = 2
        vector<int> methods = { 1 , 2 };
        methods.reserve(n);

        for(int i = 2; i < n; i++) {
            // 状态转移方程
            methods[i] = methods[i - 1] + methods[i - 2];
        }
        return methods[n - 1];
    }
};
```

## 3.3 打家劫舍

[[../../LeetCode/LeetCode题目汇总#198 打家劫舍|LeetCode 198]]：
![[../../LeetCode/LeetCode题目汇总#198 打家劫舍]]

例如给定 `cash = [2,7,9,3,1]` 的数组，我们先关注于：
- 只劫第一家时：
	- 明显地，最大窃取金额即为 `cash[0]`
- 考虑劫前两家时：
	- 最大窃取金额为 `max(cash[0], cash[1])`
- 考虑劫第三家时：
	- <font color="#c00000">此时则要分两种情况考虑</font>：
		1. 先劫取 `cash[2]` ，随后再劫取 `cash[0]`
		2. 先劫取 `cash[1]` 
- 考虑劫前四家时：
	- 此时则要考虑：
		1. 先劫取 `cash[4]` ，随后考虑这两种方案中的最大值：
			1. `cash[2]` 和 `cash[0]` 
			2. `cash[1]`
		2. 先劫取 `cash[3]` ，随后劫取 `cash[1]`
	- <span style="background:#fff88f"><font color="#c00000">此时应当注意到</font></span>：
		- 截取第 $n$ 家时，<span style="background:#fff88f"><font color="#c00000">最大收入等价于</font></span>：
			- 第 $n$ 家和前 $n-2$ 家最大劫取收入
			- 前 $n-1$ 家最大劫取收入
		- <font color="#c00000">的最大值</font>

可得状态转移方程：
$$
max\_stolen(n)=max(max_stolen(n-1), max_stolen(n-2) + cash[n]), n>=2
$$

即可得动态规划实现：

```CPP
class Solution {
public:
    int rob(vector<int>& nums) {
        // stolen[i] 表示劫取前 i 家的最大收入, 0 <= i < nums.size
        vector<int> stolen(nums.size(), 0);

        // 设置初始值
        stolen[0] = nums[0];
        if(nums.size() >= 2) {
            stolen[1] = max(nums[0], nums[1]);
        }

        for(int i = 2; i < nums.size(); i++) {
            stolen[i] = max(stolen[i - 1], stolen[i - 2] + nums[i]);
        }
        return stolen[stolen.size() - 1];
    }
};
```

## 3.4 背包问题

背包问题假设每个资源均有如下的两个要素：
- 重量
- 价值
而该问题就是指在背包容量有限的情况下，在背包中装入最有价值的资源。其可以被分为如下几个大类：

| 背包类型      | <center>核心特点</center> | <center>决策逻辑</center>   | <center>现实类比</center> |
| --------- | --------------------- | ----------------------- | --------------------- |
| **0/1背包** | 每样仅 $1$ 件             | 拿/不拿                    | 选课(这门课要么修，要么不修)       |
| **完全背包**  | 每样无限件                 | 拿 $1, 2, ..., \infty$ 件 | 买邮票(同一种邮票可以买很多张)      |
| **多重背包**  | 每样限 $k$ 件             | 拿 $1, 2, ..., k$ 件      | 促销限购(每人限购5瓶)          |
| **分组背包**  | 组内互斥                  | 组内任选 $1$ 件或不选           | 搭配套餐(饮料选一种，主食选一种)     |

其中，LeetCode Hot 100中<span style="background:#fff88f"><font color="#c00000">只有0/1背包和完全背包</font></span>，因此本笔记也不再细讲后两种背包类型。

此外，背包问题还可以分为：
- 背包组合问题：不同的选择顺序，相同的选择集合是同一个选择结果
- 背包排列问题：不同的选择顺序，相同的选择集合是<span style="background:#fff88f"><font color="#c00000">不同的</font></span><font color="#c00000">选择结果</font>，例如：
	- `选1 -> 选2 -> 选3` 
	- `选2 -> 选1 -> 选3` 

### 3.4.1 0/1背包组合问题

[[../../LeetCode/LeetCode题目汇总#2915 和为目标值的最长子序列的长度|LeetCode 2915]]：
![[../../LeetCode/LeetCode题目汇总#2915 和为目标值的最长子序列的长度]]

在传统的动态规划问题中，数组 `dp[i]` 中，自变量 `i` 表示问题的规模，例如爬楼梯问题中的楼梯数、打家劫舍问题中的家庭数等。

而在背包问题中，需要同时考虑：
- 物品规模：当前考虑到第几个物品了。即背包容量固定时，物品选择子问题维度。
- 背包容量：当前考虑到的最大背包容量。即背包容量子问题维度。
两个维度

<font color="#c00000">因此则有三部曲</font>：
- 数组 `dp[i][j]` 表示：表示前 $i$ 个物品组合中，背包容量<span style="background:#fff88f">不超过</span>/<span style="background:#fff88f">等于</span> $j$ 的情况下的<span style="background:#fff88f"><font color="#c00000"><b>最大价值</b></font></span>：
$$
dp[i][j]=max\_value
$$
- 状态转移方程：即考虑如下两种选择之间的最大值
	- <span style="background:#fff88f"><font color="#c00000">不拿</font></span>：不拿物品 $i$ 时，<font color="#c00000">对应价值</font> `dp[i - 1][j]`
	- <span style="background:#fff88f"><font color="#c00000">拿</font></span>：当考虑拿物品 $i$ 时，<font color="#c00000">对应价值</font> `v[i] + dp[i - 1][j - w[i]]`
	<font color="#c00000">之间的最大值</font>，即：
$$
max(拿, 不拿)
$$
- 初始化条件：
	- 由于状态转移时，<font color="#c00000">需要考虑是否可以凑出当前重量</font>，而非只考虑当前重量的解数，<font color="#c00000">因此数组初始化的值通常设置为</font> `-1`

注意：
1. 数组 `dp[i][j]` 表示是背包容量<font color="#c00000"><u>不超过</u></font> $j$ 还是<font color="#c00000"><u>等于</u></font> $j$ <span style="background:#fff88f"><font color="#c00000">取决于具体的题目要求</font></span>，<span style="background:#fff88f"><font color="#c00000">即是否要求背包装满</font></span>
2. 为了方便优化为一维数组形式，<font color="#c00000">通常要先遍历物品</font>，<font color="#c00000">再遍历容量</font>

#### 3.4.1.1 二维数组形式(入门使用)

对于本题，则有：
- `dp[i][j]` 表示前 $i$ 个物品组合中，背包容量<span style="background:#fff88f"><font color="#c00000"><b><u>等于</u></b></font></span> $j$ 时的最大价值
- `value[i] = 1`
- `weight[i] = nums[i]`

```CPP
class Solution {
public:
    int lengthOfLongestSubsequence(vector<int>& nums, int target) {
        // 初始化dp数组，dp[i][j] 表示前 i 个物品中，背包容量等于 j 时的最大价值
        // 初始值为-1，表示无合法组合
        vector<vector<int>> dp(nums.size() + 1, vector<int>(target + 1, -1));
		
        // 设置初始化条件：当容量为0时，组合为0
        for(int i = 0; i <= nums.size(); i++) {
            dp[i][0] = 0;
        }
		
        // i 为物品
        for(int i = 1; i <= nums.size(); i++) {
            // 定义 weight 和 val
			int weight = nums[i - 1];
			int value = 1;
            // j 为容量
            for(int j = 1; j <= target; j++) {				
                // 判定是否可拿条件：
                // 1. 背包可容下当前物品i，即：j >= weight
                // 2. 背包容量为 j - i 时有解，即：dp[i - 1][j - weight] != -1
                if(j >= weight && dp[i - 1][j - weight] != -1) {
                    // dp = max(不拿, 拿)
                    dp[i][j] = max(
                        dp[i - 1][j],                 // 不拿
                        dp[i - 1][j - weight] + value // 拿
                    );
                } else {
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }
        
        // dp[i][j] 表示前 i 个物品中，背包容量等于 j 时的最大价值
        // 因此直接返回 dp[nums.size()][target] 即可
        return dp[nums.size()][target];
    }
};
```

当然：
1. 上述 `24-32` 行中的"判定是否可拿->拿/不拿->不拿"的逻辑可以合并和精简。此处为基础讲解故不合并，后续题例中将被精简。
2. 上述的初始值 `-1` 为非法值。此处为基础讲解故不做优化，后续将统一命名和管理。
3. 上述demo不建议背诵，需背诵直达章节：[[数据结构/数据结构算法/数据结构算法基础#^jrzdet|背包问题]]。

#### 3.4.1.2 一维数组形式(推荐) ^7ph75d

明显地，在上述先遍历物品，再遍历容量的状态转移中，由于其 `dp` 数组只依赖于上一个物品的 `dp` 状态(即只依赖 `dp[i - 1]` )，因此其可以合并为一维数组的形式，但是需要注意：
1. 在对固定的 `i` 、`j` 遍历时，<span style="background:#fff88f"><font color="#c00000">其会依赖于比当前</font></span> `j` <span style="background:#fff88f"><font color="#c00000">更小的</font></span> `j - value` ：
	- `dp[i - 1][j - value]` 
2. 但是当我们保持原有逻辑从前向后遍历 `j` 时，<font color="#c00000">会导致当前</font> `j` <font color="#c00000">使用已经被更新的当前轮次的</font> `j - value` ，<font color="#c00000">从而导致逻辑错误</font>(变成[[动态规划#^5mw6t9|完全背包问题]]) ^5kjk6n
3. 因此可以将 `j` 改为<span style="background:#fff88f"><font color="#c00000">从后向前遍历</font></span>，以避免逻辑错误

```CPP
class Solution {
public:
    int lengthOfLongestSubsequence(vector<int>& nums, int target) {
        int illegal = -1;
        // 一维数组形式：dp[j] 表示容量为 j 的情况下，上一轮物品 i 的 dp 表
        vector<int> dp(target + 1, illegal);
		
        // 设置初始化条件：当容量为0时，组合为0
        dp[0] = 0;
		
        // i 为物品
        for(int i = 1; i <= nums.size(); i++) {
	        // 定义 weight 和 value
			int weight = nums[i - 1];
			int value = 1;
            // j 为容量，需要倒序遍历
            for(int j = target; j > 0; j--) {
                // 无论i、j为何值，其一定可以不拿，则：dp[j] = dp[j]
                // dp[j] = dp[j]; // 不拿
				
                // 判定是否可拿条件：
                // 1. 背包可容下当前物品i，即：j >= weight
                // 2. 背包容量为 j - i 时有解，即：[j - weight] != illegal
                if(j >= weight && dp[j - weight] != illegal) {
                    // dp = max(不拿, 拿)
                    dp[j] = max(
                        dp[j],                // 不拿
                        dp[j - weight] + value  // 拿
                    );
                }
            }
        }
		
        // dp[i][j] 表示前 i 个物品中，背包容量等于 j 时的最大价值
        // 因此直接返回 dp[nums.size()][target] 即可
        return dp[target];
    }
};
```

#### 3.4.2.1 零钱兑换 ^g0097z

[[../../LeetCode/LeetCode题目汇总#322 零钱兑换|LeetCode 322]]：
![[../../LeetCode/LeetCode题目汇总#322 零钱兑换]]

思路：
1. 本题目为完全背包问题，且：
	1. 背包必须装满
	2. 不一定有解
	3. <font color="#c00000">向小值优化</font>
2. 则：
	1. 非法值设计为 $amount + 1$ ：
		- $amount + 1$ 大于 `dp` 中的合法值
		- $amount + 1$ 可以被 $min$ 优化掉

```CPP
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
    	// 非法值大于 dp 中的合法值，且可以被 min 优化
        int illegal = amount + 1;
        // dp数组，dp[j] 表示数额为j时的最少硬币数量
        vector<int> dp(amount + 1, illegal);
		
        // 初始值：amount=0时，dp=0
        dp[0] = 0;
		
        // 遍历可找回的零钱面值
        for(int i = 1; i <= coins.size(); i++) {
            int weight = coins[i - 1];
            int value = 1;

            // 正序遍历总金额
            for(int j = 1; j <= amount; j++) {
                // 不拿：dp[j] = dp[j]
                // dp[j] = dp[j];

                // 判定可拿条件：
                // 1. j >= weight
                // 2. dp[j - weight] != illegal
                if(j >= weight && dp[j - weight] != illegal) {
                    dp[j] = min(
                        dp[j],                 // 不拿
                        dp[j - weight] + value // 拿
                    );
                }
            }
        }
        // 注意需要非法值转换
        return dp[amount] != illegal ? dp[amount] : -1;
    }
};
```

#### 3.4.2.2 完全平方数 ^9eqjkt

[[../../LeetCode/LeetCode题目汇总#279 完全平方数|LeetCode 279]]：
![[../../LeetCode/LeetCode题目汇总#279 完全平方数]]

思路：
1. 本题目可转化为完全背包问题，且：
	1. 背包必须装满，且一定可以装满(一定有解)
	2. <font color="#c00000">向小值优化</font>
	3. 在要求用物品"完全平方数 $k^2$"：
		- 重量：$k^2$
		- 价值：$1$
2. 由于该题目一定有解，因此<font color="#c00000">无须非法值相关逻辑的出现</font>

```CPP
class Solution {
public:
    int numSquares(int n) {
        // 完全背包问题直接使用一维dp数组即可
        // dp[j] 表示容量为 j 时，完全平方数的最小数量
        vector<int> dp(n + 1);
		
        // 填充初始值：当 i = 0 (即item=1)时，dp[j] = j
        for(int j = 0; j <= n; j++) {
            dp[j] = j;
        }
		
        // 遍历物品i
        int loop_times = sqrt(n) + 2;
        for(int i = 1; i < loop_times; i++) {
            int weight = i * i;
            int value = 1;
			
            // 完全背包：从前向后遍历容量j
            for(int j = 1; j <= n; j++) {
                // 不拿物品i时：dp[j] = dp[j]
                // dp[j] = dp[j];
				
                // 判定是否可拿物品 i
                // 1. 背包可容纳物品i：j >= weight
                if(j >= weight) {
                    dp[j] = min(
                        dp[j],                   // 不拿
                        dp[j - weight] + value   // 拿
                    );
                }
            }
        }
        return dp[n];
    }
};
```

注：
1. 上述逻辑中，无须提前生成物品列表(也无须 `vector<int> dp` )，在物品遍历时生成即可。(不过实测时间消耗反而增加)

## 3.5 单向数组最值问题

单向数组最值问题表示的是：
- 对于最值方法 `max_value()`
- 其元素 `nums[i]` 处的最值方法 `max_value()` <span style="background:#fff88f"><font color="#c00000"><b><u>只</u></b>依赖于其前面</font></span>(或后面)<font color="#c00000">的优化结果</font> `dp[0:i-1]` 
- 即：`dp[i] = max_value(dp[0:i-1], nums[i])`

其可以有如下的分类方式：
- 按切片方法分：
	- 可间断切割：执行 `max_value` 时，其需要参考 `dp[0], dp[1], ..., dp[i-1]` 的所有值
		- 时间复杂度 $O(n^2)$ ，需要两轮循环
		- 空间复杂度 $O(n)$
		- [[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#300 最长递增子序列|LeetCode 300]]
	- 连续切片：执行 `max_value` 时，其需要参考 `dp[i-1]` 
		- 时间复杂度 $O(n)$ ，只需一轮循环
		- 空间复杂度 $O(1)$ ，数组 `dp[n]` 可退化为单元素值
		- [[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#152 乘积最大子数组|LeetCode 152]]

### 3.5.1 最长递增子序列(LIS)

[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#300 最长递增子序列|LeetCode 300]]：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#300 最长递增子序列]]

本方法无法使用背包问题。

考虑动态规划：
- 定义状态数组： `dp[i]` 以 `nums[i]` 元素<span style="background:#fff88f"><font color="#c00000"><b><u>为结尾的</u></b></font></span>最长上升子序列长度
- 定义状态转移方程：对于 `j < i` 当 `num[j] < nums[i]` 时，取 `max(nums[j] + 1, nums[i])` ，即伪代码：
```CPP
for(j < i) {
	if(nums[j] < nums[i]) {
		nums[i] = max(nums[j] + 1, nums[i]);
	}
}
```
- 初始化：`dp[all] = 1`

```CPP
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        int max_len = 1;
        // dp[i]：以 nums[i] 为结尾的最长递增序列长度
        vector<int> dp(n, 1);
        dp[0] = 1;
		
        for(int i = 0; i < n; i++) {
            for(int j = 0; j < i; j++) {
                if(nums[i] > nums[j]) {
                    dp[i] = max(dp[j] + 1, dp[i]);
                    max_len = max(max_len, dp[i]);
                }
            }
        }
		
        return max_len;
    }
};
```

### 3.5.2 乘积最大子数组

![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#152 乘积最大子数组]]

需要注意：
- 由于存在负负得正的情况，因此需要维护两个 `dp` 数组，分别记录最大最小值，以免两个负数相乘的结果大于正值 `dp` 中的最大值的情况

考虑动态规划：
- 定义状态数组： `dp_max/min[i]` 以 `nums[i]` 为结尾的连续子序列乘积的最大/最小值
- 定义状态转移方程：
	- `dp_min[i] = min(dp_min[i - 1] * nums[i], nums[i], dp_max[i - 1] * nums[i])`
	- `dp_max[i] = max(dp_max[i - 1] * nums[i], nums[i], dp_min[i - 1] * nums[i])`

```CPP
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();
        // dp[i]：以 nums[i] 为结尾的非空最大连续子数组的乘积
        // 初始化为 nums
        vector<int> dp_max = nums;
        vector<int> dp_min = nums;
		
        int max_value = nums[0];
		
        for(int i = 1; i < n; i++) {
            dp_min[i] = min(
                {dp_min[i - 1] * nums[i], nums[i], dp_max[i - 1] * nums[i]}
            );
            dp_max[i] = max(
                {dp_max[i - 1] * nums[i], nums[i], dp_min[i - 1] * nums[i]}
            );
            max_value = max(max_value, dp_max[i]);
        }
		
        return max_value;
    }
};
```

明显地，由于<font color="#c00000">本题为连续子序列问题</font>，因此其只依赖于 `dp[i - 1]` ，<font color="#c00000">因此可将</font> `dp` <font color="#c00000">数组优化为单独的最值</font>：

```CPP
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();
        int last_max = nums[0];
        int last_min = nums[0];
		
        int max_value = nums[0];
		
        for(int i = 1; i < n; i++) {
            int curr_min = min(
                { last_min * nums[i], nums[i], last_max * nums[i]}
            );
            int curr_max = max(
                { last_max * nums[i], nums[i], last_min * nums[i]}
            );
			
            last_max = curr_max;
            last_min = curr_min;
            max_value = max(max_value, last_max);
        }
		
        return max_value;
    }
};
```
