# 2 实现与边界条件

[[../../LeetCode/LeetCode题目汇总#35 搜索插入位置|LeetCode 35]]：
![[../../LeetCode/LeetCode题目汇总#35 搜索插入位置]]

二分法搜索的关键点是边界条件的控制，通常来说边界条件有如下两种：
- <span style="background:#fff88f"><font color="#c00000">左闭右闭</font></span>：`[left, right]` (<span style="background:#fff88f"><font color="#c00000">推荐</font></span>)
	- <font color="#c00000">循环条件</font>：`left<=right`
	- 中指针：`(left+right)/2` (向下取整，不考虑溢出)
	- 指针更新：
		- 左指针：`left = middle + 1`
		- <font color="#c00000">右指针</font>：`right = middle - 1`
- 左闭右开：`[left, right)`
	- <font color="#c00000">循环条件</font>：`left<right`
	- 中指针：`(left+right)/2` (向下取整，不考虑溢出)
	- 指针更新：
		- 左指针：`left = middle + 1`
		- <font color="#c00000">右指针</font>：`right = middle` (因为右侧为开区间)

那么针对左闭右闭的版本，有如下代码：

```CPP
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        // 左闭右闭版本，即 [left, right]
        int left = 0, right = nums.size() - 1;
        // 中指针
        int middle = 0;
        // 循环条件为 left <= right
        while(left <= right) {
            // 两个版本中指针均为 (left + right) / 2
            middle = (left + right) / 2;
            
            if(nums[middle] < target) {
                left = middle + 1;
            } else if(nums[middle] > target) {
                right = middle - 1;
            } else {
            	// 找到目标值
                return middle;
            }
        }
        // 未找到值
        // 此时nums[right] < target < nums[left]
        // 即插入到 left 所在位置
        return left;
    }
};
```

注意：
1. 在第 `25` 行中，若：
	1. 返回 `-1` 则表示<font color="#c00000">未搜索到目标值</font>(类似于 `std::binary_search`)
	2. 返回 `left` 则表示<font color="#c00000">在目标值之后的第一个索引</font>(等价于 `std::upper_bound`)
	3. 返回 `right` 则表示<font color="#c00000">在目标值之前的第一个索引</font>(等价于 `std::lower_bound` - 1)
