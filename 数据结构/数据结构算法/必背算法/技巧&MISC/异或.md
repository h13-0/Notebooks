# 2 异或

异或的基本特性：
1. <font color="#c00000">任何数和自己做异或运算</font>，结果为0
2. <font color="#c00000">异或满足交换律</font>
3. 任何数和0做异或运算，结果为其原值

[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#136 只出现一次的数字|LeetCode 136]]：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#136 只出现一次的数字]]

那么上述题目就可以考虑使用特性1和2，从而：

```CPP
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int result = 0;
        for (const auto& num : nums) {
            result ^= num;
        }
        return result;
    }
};
```
