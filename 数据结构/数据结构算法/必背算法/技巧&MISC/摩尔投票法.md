# 2 摩尔投票法

摩尔投票法可以找出"<span style="background:#fff88f"><font color="#c00000">出现次数大于n/k的元素</font></span>"，

## 2.1 找出多半选票

[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#169 多数元素|LeetCode 169]]：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#169 多数元素]]

本题使用哈希表，可以很简单的实现时间复杂度 $O(1)$ 、空间复杂度 $O(n)$ 的解法。
不过使用摩尔投票，可以使空间复杂度也降低到 $O(1)$ ：

```CPP
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int candidate = 0;
        int count = 0;
		
        for (int num : nums) {
            if (count == 0)
                candidate = num;
			
            if (num == candidate)
                count++;
            else
                count--;
        }
		
        return candidate;
    }
};
```
