![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#78 子集|LeetCode 78]]

子集可以看作一个选择问题，例如用 `0` 表示不选，`1` 表示选中，则可以有如下的表示：

|     子集      | 0/1序列 |
| :---------: | :---: |
|    `{1}`    |  100  |
|    `{2}`    |  010  |
|    `{3}`    |  001  |
|    `{}`     |  000  |
|  `{2, 3}`   |  011  |
|  `{1, 3}`   |  101  |
|  `{1, 2}`   |  110  |
| `{1, 2, 3}` |  111  |
而对于 `n` 个数构成的选择问题，其对应的集合为 $[0, 2^n]$ 。因此可以直接依赖上述映射关系，对于 $[0, 2^n]$ 范围内的整数执行映射，即得全子集。

```CPP
class Solution {
public:
    vector<int> t;
    vector<vector<int>> ans;
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        for (int mask = 0; mask < (1 << n); ++mask) {
            t.clear();
            for (int i = 0; i < n; ++i) {
                if (mask & (1 << i)) {
                    t.push_back(nums[i]);
                }
            }
            ans.push_back(t);
        }
        return ans;
    }
};
```
