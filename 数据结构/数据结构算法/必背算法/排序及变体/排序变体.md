# 2 基本概念

在部分题目中，若其可以直接使用"排序后的部分特性"进行解题时，则可以考虑基于部分排序算法进行改造，相比于走完完整的排序流程，使其可以更快的完成任务。

不过通常来说本类题型收益没有那么大，因此往往不是那么重要。

# 3 例题

## 3.1 排序选择

[[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#215 数组中的第K个最大元素|LeetCode 215]]：
![[数据结构/数据结构算法/LeetCode/LeetCode题目汇总#215 数组中的第K个最大元素]]

明显地，先使用 $O(nlogn)$ 的排序，再直接访问元素是最简单的写法。
不过可以考虑改造 $O(nlogn)$ 的排序，使其提前结束并完成任务。

常用 $O(nlogn)$ 排序方法有：
- 快速排序

基于快速选择的解法：
1. 快速排序每一轮都会确定一个 `pivot` 的最终位置，并确保其左右值域被 `pivot` 切分
2. 因此如果 `pivot` ：
	1. 恰巧位于第k大的位置，则可以直接结束
	2. 第k大位置位于 `pivot` 一侧，则 `pivot` 另一侧可以停止后续排序任务
