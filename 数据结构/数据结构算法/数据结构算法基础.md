#### 3.3.1.1 环形缓冲区

普通环形缓冲区可有如下的设计：
1. 牺牲一个存储单元，从而避免使用额外的 `size` 来实现判空判满
2. 当 `head = tail` 时为空
3. 当 `(head + 1) % size = tail` 时为满
4. 入队出队时指针 `+1` 即可

```CPP
#include <vector>
#include <iostream>

template <typename T>
class RingBuffer {
public:
    // 初始化时分配 capacity + 1 的空间
    // 用户申请 N 个空间，实际底层分配 N+1
    explicit RingBuffer(size_t capacity) 
        : buffer_(capacity + 1), max_size_(capacity + 1), head_(0), tail_(0) {}

    // 判满逻辑
    bool isFull() const {
        // 如果 head 往前走一步撞上了 tail，就是满了
        return (head_ + 1) % max_size_ == tail_;
    }

    // 判空逻辑
    bool isEmpty() const {
        // 如果 head 和 tail 指向同一个位置，就是空的
        return head_ == tail_;
    }

    // 入队 (Write)
    bool push(const T& value) {
        if (isFull()) {
            return false;
        }
        buffer_[head_] = value;
        // 移动 head，并处理回绕
        head_ = (head_ + 1) % max_size_;
        return true;
    }

    // 出队 (Read)
    bool pop(T& value) {
        if (isEmpty()) {
            return false;
        }
        value = buffer_[tail_];
        // 移动 tail，并处理回绕
        tail_ = (tail_ + 1) % max_size_;
        return true;
    }

    // 获取当前元素个数
    size_t size() const {
        if (head_ >= tail_) {
            return head_ - tail_;
        }
        return max_size_ - (tail_ - head_);
    }

    // 获取总容量（用户可用的最大容量）
    size_t capacity() const {
        return max_size_ - 1;
    }

private:
    std::vector<T> buffer_;
    size_t max_size_; // 实际物理大小
    size_t head_;     // 写索引
    size_t tail_;     // 读索引
};
```

#### 3.3.1.2 无锁环形缓冲区

```CPP
#include <atomic>
#include <vector>

template <typename T>
class SimpleLockFreeQueue {
public:
    explicit SimpleLockFreeQueue(size_t capacity) 
        : buffer(capacity + 1), head(0), tail(0) {}

    // 仅生产者调用
    bool push(const T& val) {
        size_t h = head.load(std::memory_order_relaxed);
        size_t next_h = (h + 1) % buffer.size();

        // 检查 tail (acquire 确保读取到消费者最新的 tail)
        if (next_h == tail.load(std::memory_order_acquire)) {
            return false; // 队列满
        }

        buffer[h] = val; // 写入数据
        
        // 更新 head (release 确保数据写入对消费者可见)
        head.store(next_h, std::memory_order_release);
        return true;
    }

    // 仅消费者调用
    bool pop(T& val) {
        size_t t = tail.load(std::memory_order_relaxed);

        // 检查 head (acquire 确保读取到生产者最新的 head 和数据)
        if (t == head.load(std::memory_order_acquire)) {
            return false; // 队列空
        }

        val = buffer[t]; // 读取数据

        // 更新 tail (release 告诉生产者该位置已空闲)
        tail.store((t + 1) % buffer.size(), std::memory_order_release);
        return true;
    }

private:
    std::vector<T> buffer;
    std::atomic<size_t> head;
    std::atomic<size_t> tail;
};
```

```C
int binary_search(int nums[], int n, int target) {
    int l_index = 0, r_index = n - 1;
    while(l_index <= r_index)
    {
        int mid = (l_index + r_index) / 2;
        if(nums[mid] == target)
            return mid;
        else if(nums[mid] > target)
            r_index = mid - 1;
        else
            l_index = mid + 1;
    }
    return -1;
}
```

## 3.5 算法分类
### 3.5.1 原地算法(in-place algorithm)

维基百科：
	原地算法是指基本上不需要借助额外的数据结构就能对输入的数据进行变换的算法。不过，分配少量空间给部分辅助变量是被允许的。算法执行过程中，输入的数据往往会被输出结果覆盖。原地算法只能通过替换或交换元素的方式来修改原始的输入。不满足“原地”原则的算法也被称为非原地（not-in-place）算法或异地（out-of-place）算法。


### 3.5.2 分治算法

当人们要解决一个输入规模，比如n，很大的问题时，往往会想到将该问题分解。比如将这n个输入分成k个不同的子集。如果能得到k个不同的可独立求解的子问题，而且在求出这些子问题的解之后，还可以找到适当的方法把它们的解合并成整个问题的解，那么复杂的难以解决的问题就可以得到解决。这种将整个问题分解成若干个小问题来处理的方法称为分治法。

#### 3.5.2.1 经典实例

分治算法的经典实例有：

2. 快速排序

4. 最大子数组问题
