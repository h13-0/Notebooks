# 2 面相对象的基本特性

## 2.1 类




### 2.1.1 构造函数

构造函数主要有如下几种类别：
1. 默认构造函数
2. 含参构造函数
3. 拷贝构造函数
	- 注：拷贝构造函数并不是赋值构造函数，赋值构造函数的本质是赋值运算符重载(即赋值构造并不是构造函数的一种)
4. 移动构造函数
5. 委托构造函数
6. 显式构造函数

#### 2.1.1.1 默认构造函数

默认构造函数是指不需要指定参数时的构造函数，其在部分语言中有特殊功能和特殊用法，因此单独成一类。

特殊功能有：
- C++在使用一些标准库容器(如 `std::vector` 、 `std::list` 等)时，要求其所存储的对象必须提供一个默认构造函数。
- C++或者Java等语言使用第三方库时可能会要求其使用的类包含默认构造函数。
- 延迟初始化。
- 在C++中，使用该对象构造数组时，该对象必须提供一个默认构造函数。
特殊用法：
1. 在C++中，<span style="background:#fff88f"><font color="#c00000">调用默认构造函数的方法并不是</font></span> `ClassName obj();` ，<span style="background:#fff88f"><font color="#c00000">而是</font></span> `ClassName obj;` ，<span style="background:#fff88f"><font color="#c00000">前者是声明了一个返回值类型为ClassName的函数</font></span>。
```CPP
// 调用默认构造函数
ClassName obj;

// 声明一个返回值为ClassName的函数，函数名为obj
ClassName obj();
```

##### 2.1.1.1.1 C++的默认构造函数及其调用

在C++中，有以下两种方式可以定义默认构造函数：
1. 如果开发者没有显式地声明任何构造函数，编译器会自动生成一个默认构造函数(<font color="#c00000">但是并不会初始化类中的变量</font>)。
```CPP
class Cat {
public:
	void printInfo(void);

private:
	// 品种
	std::string breed;
	float weight;
	float age;
};

void Cat::printInfo(void)
{
	using namespace std;
	cout << "breed: " << breed << endl;
	cout << "weight: " << weight << endl;
	cout << "age: " << age << endl;
}

int main()
{
	// 无参构造，默认生成的默认构造函数并不会初始化类中变量
	Cat cat1;
	// 行为未定义
	cat1.printInfo();
	return 0;
}
```
- 注意：
	- <span style="background:#fff88f"><font color="#c00000">在上述代码中，编译器自动生成的构造函数所生成的对象中的breed等成员变量均未被初始化</font></span>(当然在C++11之后，允许在类的定义中直接定义成员的默认值)。
	- <span style="background:#fff88f"><font color="#c00000">若类中已经提供了构造函数，则编译器不会生成默认构造函数</font></span>，上述代码第23行就会报错。
2. 开发者可以显式定义默认构造函数。在自定义的默认构造函数中可以进行填装初始值等操作。

#### 2.1.1.2 含参构造函数

含参构造函数即在创建类时需要指定若干参数。最为常用的方法。

#### 2.1.1.3 拷贝构造函数

<font color="#c00000">拷贝构造函数用于创建一个对象作为另一个对象的副本</font>。

##### 2.1.1.3.1 C++的拷贝构造函数

C++的拷贝构造函数形式为：`ClassName(const ClassName &obj)` 。
<span style="background:#fff88f"><font color="#c00000">需要注意的是在C++中，拷贝构造函数会被默认生成，其实现方式为浅拷贝</font></span>。浅拷贝的规则如下：
- 对于类的每一个非静态成员变量，使用其对应的赋值操作进行拷贝。
- 对于内置类型(如 `int` 、 `double` )，会进行直接的值复制。
- 对于指针类型，默认的拷贝构造函数只会复制指针的地址（这就是浅拷贝），而不会复制指针所指向的内容。
自定义的拷贝构造函数中可以实现自定义的逻辑。

```CPP
class Cat {

public:
	void printInfo(void);
	
	// 默认构造函数
	Cat() : breed("default"), weight(0), age(0) {
		std::cout << "Called the default constructor." << std::endl;
	};

	// 含参构造函数
	Cat(std::string breed, float weight, float age) : breed(breed), weight(weight), age(age) {
		std::cout << "Called a constructor with parameters." << std::endl;
	};

	// 拷贝构造函数
	Cat(const Cat &cat) : breed(cat.breed), weight(cat.weight), age(cat.age) {
		std::cout << "Called the copy constructor." << std::endl;
	};

	// 重载operator=运算符
	Cat& operator=(const Cat& cat) {
		std::cout << "Called the operator=." << std::endl;
		this->breed = cat.breed;
		this->weight = cat.weight;
		this->age = cat.age;
		return *this;
	};

private:
	// 品种
	std::string breed;
	float weight;
	float age;
};

void Cat::printInfo(void)
{
	using namespace std;
	cout << "breed: " << breed << endl;
	cout << "weight: " << weight << endl;
	cout << "age: " << age << endl;
}

int main()
{
	// 含参构造
	Cat cat1 = Cat("British shorthair cat", 1.0, 0.75);
	cat1.printInfo();

	// 拷贝构造
	Cat cat2 = Cat(cat1);
	cat2.printInfo();

	// 同样是拷贝构造
	Cat cat3 = cat1;
	cat3.printInfo();

	// 调用赋值运算函数
	cat3 = cat1;
	return 0;
}
```

则上述的：
- `Cat cat2 = Cat(cat1);` 
- `Cat cat3 = cat1;`
会调用拷贝构造函数。

#### 2.1.1.4 移动构造函数

移动(move)构造函数的 `move` 是类似于linux指令的move，类比如下：
- 拷贝(copy)构造：需要保留原对象，并构造新对象
- 移动(move)构造：<font color="#c00000">不需要保留原对象</font>，并构造新对象。其中：
	- 其<font color="#c00000">被移动到新对象的成员会被置空</font>。
		- 在C++中，被移动走的对象会处于"有效但未定义的状态"
	- 其<font color="#c00000">被拷贝到新对象的成员不会变化</font>。
通过定义移动构造，可以避免资源拷贝，提升执行效率。

##### 2.1.1.4.1 C++的移动构造函数

例如如下的动态数组示例：

```CPP
#include <iostream>
#include <string>

class Cat
{
private:
    std::string name = "unnamed";
    std::string owner = "none";
public:
    // 含参构造函数
    Cat(std::string name, std::string owner) :name(name), owner(owner)
    {
        std::cout << "The parameterized constructor is called, name = " << name << std::endl;
    }

    // 移动构造函数
    // 需要注意：这里仅对name做移动构造，对owner做拷贝构造，从而演示区别
    Cat(Cat&& cat) noexcept : name(std::move(cat.name)), owner(cat.owner)
    {
        std::cout << "The move constructor is called, name = " << name << std::endl;
    }

    // 析构函数
    ~Cat()
    {
        std::cout << "The destructor is called, name = " << name << std::endl;
    }

    // Getters and setters
    std::string get_name() { return name; }
    void set_name(std::string new_name) { name = new_name; }
    std::string get_owner() { return owner; }
    void set_owner(std::string new_owner) { owner = new_owner; }
};

int main(int argc, char** argv) 
{
    Cat cat1("cat1", "old owner");

    // 将cat1移动到new_cat
    Cat new_cat(std::move(cat1));
    std::cout << "The name of new_cat is: " << new_cat.get_name() << std::endl;
    std::cout << "The owner of new_cat is: " << new_cat.get_owner() << std::endl;

    // 为new_cat重命名
    new_cat.set_name("new_cat");
    std::cout << "The new name of new_cat is: " << new_cat.get_name() << std::endl;

    // 尝试访问旧对象及成员
    std::cout << "The name of old cat is: " << cat1.get_name() << std::endl;
    std::cout << "The owner of old cat is: " << cat1.get_owner() << std::endl;

    return 0;
}
```

为了形成对比，上述对象的移动构造函数中：
- 成员 `name` 选择移动构造
- 成员 `owner` 选择拷贝构造
则其运行结果为：

```text
The parameterized constructor is called, name = cat1
The move constructor is called, name = cat1
The name of new_cat is: cat1
The owner of new_cat is: old owner
The new name of new_cat is: new_cat
The name of old cat is:
The owner of old cat is: old owner
The destructor is called, name = new_cat
The destructor is called, name =
```

C++移动构造函数的特性有：
1. 当成员被移动到新的对象时，<font color="#c00000">其老对象的该成员会进入</font>"<span style="background:#fff88f"><font color="#c00000">有效但未定义的状态</font></span>"：
	- 可以安全的调用其析构函数
	- 可以安全的调用不依赖其值的函数
	- 依赖其具体值的函数可以被调用，但是结果未定义(例如上方的 `name` 成员)
2. 同样的，<font color="#c00000">被移动的老对象也会进入</font>"<font color="#c00000">有效但未定义的状态</font>"，与上一条互相嵌套(成员即对象，对象即成员)
3. 当对象支持移动构造时，编译器会优先对函数返回值使用移动构造
4. <font color="#c00000">当对象满足如下条件时</font>，<font color="#c00000">编译器自动生成移动构造函数</font>：
	1. 用户未声明以下构造函数的任何一个：
		- 拷贝构造函数
		- 拷贝赋值运算符
		- 移动赋值运算符
		- 析构函数
		- 移动构造函数
	2. 且所有非静态成员支持移动<u>语义</u>：
		1. 若支持拷贝但不支持移动，则自动生成的移动构造函数会使用拷贝方式
		2. 若不支持移动也不支持拷贝，<font color="#c00000">则不生成移动构造函数</font>(<font color="#c00000">移动构造被定义为删除</font>)
5. 用户可通过 `Class(Class &&)=default;` 显示请求生成移动构造函数

#### 2.1.1.5 委托构造函数

委托构造函数主要是<font color="#c00000">允许类中的一个构造函数调用同一个类中的另一个构造函数</font>，从而提高代码复用性。

##### 2.1.1.5.1 C++的委托构造函数

```CPP
class MyClass {
public:
    // 目标构造函数
    MyClass(int a, double b) : x(a), y(b) {
        // 初始化逻辑
    }

    // 委托构造函数：通过初始化列表调用另一个构造函数
    MyClass(int a) : MyClass(a, 3.14) {  // 委托给第一个构造函数
        // 可添加额外逻辑（可选）
    }

    // 另一个委托构造函数
    MyClass() : MyClass(0, 0.0) {}  // 委托给第一个构造函数

private:
    int x;
    double y;
};
```

此外，需要注意：
1. C++的委托构造函数可以委托给基类的构造函数，可见[[面向对象的程序设计#^toefs7]]。

#### 2.1.1.6 显式构造函数

显式构造函数主要是为了防止编译器的隐式转换和对象的意外构造，例如：

C++中的隐式转换：

```CPP
class Temperature {
public:
    Temperature(double celsius) : value(celsius) {}

private:
    double value;
};

void setTemperature(Temperature temp) {
    // 设置温度
}

int main() {
	Temperature temp = 25.0;           // 正确：触发隐式构造
    setTemperature(25.0);              // 正确：触发隐式转换
    setTemperature(Temperature(25.0)); // 正确：显式构造
    return 0;
}
```

`C#` 中的隐式转换：

```C#
public class Temperature
{
    private double Celsius { get; }
    
    public Temperature(double celsius)
    {
        Celsius = celsius;
    }
    
    // 定义隐式转换运算符
    public static implicit operator Temperature(double celsius)
    {
        return new Temperature(celsius);
    }
}

class Program
{
    static void SetTemperature(Temperature temp)
    {
        Console.WriteLine($"Temperature: {temp.Celsius}°C");
    }
    
    static void Main()
    {
        // 使用隐式转换
        SetTemperature(25.0); // 自动调用隐式转换运算符
        
        // 显式创建对象（仍然有效）
        SetTemperature(new Temperature(30.0));
    }
}
```

不过：
- 大多数语言都不支持隐式转换，如Java。
- 少数语言可选地支持隐式转换，如 `C#` 、Scala等<font color="#c00000">需要手动开启隐式转换特性</font>。
- 而在C++中则<font color="#c00000">默认开启隐式转换功能</font>，<font color="#c00000">需要对应的显式构造函数来关闭该特性</font>。

##### 2.1.1.6.1 C++的显式构造函数

在C++中，其主要通过[[C2CPP#^6nhi9i|explicit 强制显式转换]]进行显式构造，例如上方C++中的 `Temperature` 类可以如下地关闭隐式转换、或者说修改为显式构造函数：

```CPP
class Temperature {
public:
    explicit Temperature(double celsius) : value(celsius) {}
    
private:
    double value;
};

void setTemperature(Temperature temp) {
    // 设置温度
}

int main() {
	// Temperature temp = 25.0;        // 错误：不能隐式构造
    // setTemperature(25.0);           // 错误：不能隐式转换
    setTemperature(Temperature(25.0)); // 正确：显式构造
    return 0;
}
```

注：
- 在C++中，<span style="background:#fff88f"><font color="#c00000">任何可能被意外调用的构造函数均应修改为显式构造函数</font></span>，<font color="#c00000">尤其是只含一个非默认参数的构造函数</font>。
- <font color="#c00000">对C++的单参构造函数</font>，<span style="background:#fff88f"><font color="#c00000">应当始终使用</font></span> `explicit` ，除非有意允许隐式转换

#### 2.1.1.7 转换构造函数(隐式转换)

转换构造函数即上一章节中允许隐式转换的构造函数。

##### 2.1.1.7.1 C++的转换构造函数

<font color="#c00000">在C++中</font>，<font color="#c00000">不使用</font> `explicit` 的<font color="#c00000">只有一个非默认参数的构造函数</font>即为转换构造函数。

#### 2.1.1.8 条件性显式构造函数

##### 2.1.1.8.1 C++的条件性显式构造函数

在C++中，条件性显式的语法为 `explicit(cond)` ：

```CPP
template <typename T>
class Wrapper {
public:
    // 当T是整数类型时为显式，否则隐式
    explicit(std::is_integral_v<T>) Wrapper(T value) 
        : value_(value) {}
private:
    T value_;
};

Wrapper<int> w1 = 42;   // 错误：显式构造函数
Wrapper<std::string> w2 = "hello"; // 允许：隐式转换
```

#### 2.1.1.9 继承构造函数

派生类直接继承基类的构造函数即为继承构造函数。

##### 2.1.1.9.1 C++的继承构造函数

在C++中，<font color="#c00000">继承构造函数必须继承基类所有的构造函数</font>，<font color="#c00000">且不能追加自己的逻辑</font>：

```CPP
class Base {
public:
    Base(int) {}
    Base(int, double) {}
};

class Derived : public Base {
public:
    using Base::Base;  // 继承Base的所有构造函数
    // 自动生成：Derived(int) 和 Derived(int, double)
};
```

当然，<font color="#c00000">允许派生类额外追加其他参数类型的构造函数</font>，也<font color="#c00000">允许自定义构造函数覆盖继承构造函数</font>。

当派生类只需要继承其中某些基类的构造函数、或需要在基类的构造函数后添加自定义逻辑时，应当使用委托构造函数： ^toefs7

```CPP
class Base {
public:
    Base(int) {}
    Base(int, double) {}
};

class Derived : public Base {
public:
    // 只继承Base(int)这个构造函数(实际上是委托构造)，并追加自己的逻辑
	Derived(int i) : Base(i) {
		std::cout << "Derived constructed with int " << i << std::endl;
	}
    // 不继承Base(int, double)，所以不能通过Derived(int, double)构造
};
```

#### 2.1.1.10 编译期构造函数

编译器构造函数即可在编译期执行的构造函数。

##### 2.1.1.10.1 C++的编译期构造函数(constexpr)

C++的编译期构造函数要求：
1. 函数体必须为空
2. 所有成员依靠初始化列表初始化
3. 初始化表达式必须为常量表达式
随后可以使用 `constexpr` 即可使对应的对象在编译期完成构造。

```CPP
class Point {
public:
    constexpr Point(double x = 0, double y = 0) : x(x), y(y) {}
    constexpr double getX() const { return x; }
private:
    double x, y;
};

constexpr Point origin;          // 编译期构造
constexpr Point unit(1.0, 0.0);  // 编译期构造
```

#### 2.1.1.11 泛型构造函数与推导指引

与普通函数一样，构造函数也允许模板与泛型。
而推导指引则允许：
1. 将某个类型隐式转换为另外一种类型
2. 在编译器无法自动推导出对应的类模板参数时，可以对其进行指引

##### 2.1.1.11.1 C++的泛型构造函数与推导指引

C++的泛型构造函数允许传入任意类型的对象并进行构造，不过其优先级小于非泛型构造函数，例如：

```CPP
template <typename T>
class Wrapper {
public:
    T value;
    
    // 泛型构造函数
    template <typename U>
    Wrapper(U&& arg) : value(std::forward<U>(arg)) {
        std::cout << "Generic constructor called\n";
    }
    
    // 特化构造函数(非泛型)
    Wrapper(const char* str) : value(std::string(str)) {
        std::cout << "const char* specialization\n";
    }
};
  
Wrapper w1(42);                   // 调用泛型构造函数，T=int
Wrapper w2("Hello");              // 调用const char*特化
Wrapper w3(std::string("World")); // 调用泛型构造函数
```

而当我们需要将某个类型隐式转换为另外一种类型时，可以使用推导指引：

```CPP
template <typename T>
class Wrapper {
public:
    T value;
    
    // 泛型构造函数
    template <typename U>
    Wrapper(U&& arg) : value(std::forward<U>(arg)) {
        std::cout << "Generic constructor called\n";
    }
};

// 使用推导指引，将const char*指引到std::string
Wrapper(const char*) -> Wrapper<std::string>;

Wrapper w1(42);                   // 调用泛型构造函数，T=int
Wrapper w3(std::string("World")); // 调用泛型构造函数，T=std::string
Wrapper w2("Hello");              // 被指引到std::string，同上
```


#### 2.1.1.12 聚合初始化

聚合初始化主要用于初始化一些简单的数据结构，如：
- 简单数据传输对象
- 配置参数对象
- 数学向量、矩阵
等。在此种情况下，语言可以提供类似于C语言结构体的初始化方式，而非函数构造形式。

##### 2.1.1.12.1 C++的聚合初始化 ^vuawz5

在C++中，聚合初始化的条件为：
1. 用户未提供任何的构造函数(包括显式声明使用默认构造函数或删除构造函数)
2. 没有提供 `private` 或 `protected` 成员
3. 没有基类
4. 没有虚函数

## 2.2 继承

在C++中，继承可以按照如下几个维度进行分类：
1. 按[[面向对象的程序设计#^ku99b2|继承权限]]分：包含 `public` 、 `protected` 、 `private` 三种
2. 按父类个数分：单继承、多继承
3. 按是不是虚继承分：普通继承、虚继承

而在Java中，继承有两种方式：
1. <font color="#c00000">类继承类</font> 或者 <font color="#c00000">接口继承接口</font>：此时应当使用 `extends` 特性。<font color="#c00000">该特性主要用来扩展类的功能</font>。子类继承父类后，除了可以获得父类的属性和方法外，还可以添加新的属性和方法，或者覆盖(Override)父类的方法。
2. <font color="#c00000">类实现接口</font>：此时应当使用 `implements` 特性。<font color="#c00000">当使用该特性时</font>，<span style="background:#fff88f"><font color="#c00000">该类必须实现对应接口的所有方法</font></span>(<font color="#c00000">除非该类被声明为抽象类</font>)。<font color="#c00000">该特性确保了使用implements的非抽象类能满足对应接口所要求的所有行为规范</font>。

而在继承时，基类总是先于派生类构造(CPP)

### 2.2.1 继承权限(CPP) ^ku99b2

按照继承权限分：
- 子类 `public` 继承父类，<font color="#c00000">则父类所有属性保持原权限</font>
- 子类 `protected` 继承父类，<font color="#c00000">则父类属性最高为</font> `protected` <font color="#c00000">属性</font>
- 子类 `private` 继承父类，<font color="#c00000">则父类属性最高为</font> `protected` <font color="#c00000">属性</font>

此外，在父子属性上：
- `public` 继承是 `is a` 关系，例如 `Cat : public Animal` ：
	- 在C++中，<font color="#c00000">可以直接将</font> `Cat` <font color="#c00000">转换为</font> `Animal` <font color="#c00000">类型</font>(其他继承权限不行)
	- 可以说 `Cat is a Animal` 
	- <font color="#c00000">可以理解为"子类实现了某种更具体的Base对象"</font>
- `private` 继承通常是 `has a` 关系：
	- <font color="#c00000">可以理解为"用Base来实现子类"</font>
- `protected` 继承很少使用，在搭建框架时可用于控制类型

|                   | 子类 `public` 继承 | 子类 `protected` 继承 | 子类 `private` 继承 |
| ----------------- | -------------- | ----------------- | --------------- |
| 基类属性为 `public`    | `public`       | `protected`       | `private`       |
| 基类属性为 `protected` | `protected`    | `protected`       | `private`       |
| 基类属性为 `private`   | 不可访问           | 不可访问              | 不可访问            |

### 2.2.2 虚继承(CPP) ^p6lbh3

虚继承用于解决<span style="background:#fff88f"><font color="#c00000">对同一个基类的</font></span>多重继承中，子对象重复的问题(也即菱形或类菱形继承，<span style="background:#fff88f"><font color="#c00000">不同基类的同名成员无法处理</font></span>)。
基本定义：
- <font color="#9bbb59">虚基类</font>：被虚继承的类叫作子类的虚基类，例如 `B: virtual A` 中<font color="#c00000">A就是B的虚基类</font>，<font color="#c00000">其与被继承类是否包含虚拟继承无关</font>
- <font color="#9bbb59">非虚基类</font>：被实继承的类叫作子类的实基类
- <font color="#9bbb59">直接基类</font>：被直接继承的基类(区分于被间接继承)

其有如下的基本规则：
1. `virtual` <font color="#c00000">用于指定单次的继承关系</font>
2. 对于类菱形继承：
	- <font color="#c00000">最终子类的所有继承路径必须完全为虚继承时才会被合并为一个</font>，可见[[面向对象的程序设计#^gnqqw0|成员副本保留实例]]
	- <font color="#c00000">每多一个非完全虚继承路径就会多一个副本</font>
3. <font color="#c00000">最终被实例化的对象执行该成员的构造，中间类的构造无效</font>，可见例[[面向对象的程序设计#^okzboq|子类构造实例]]；
4. 子类构造时，链路上的<font color="#c00000">每个子类递归执行如下顺序</font>：
	1. 按声明顺序构造所有虚基类
		- 声明顺序为继承列表从左到右、从最深向外遍历
	2. 按继承顺序<font color="#c00000">从左到右</font>构造<font color="#c00000">所有非虚直接基类</font>
	3. 按声明顺序构造所有非静态成员变量
	4. 执行当前类的构造函数体
	可见例[[面向对象的程序设计#^okzboq|子类构造实例]]。

<span style="background:#fff88f"><font color="#c00000">上述规则通常来说不重要</font></span>，只需要记得：
 1. 虚继承特性的目的是为了解决<span style="background:#fff88f"><font color="#c00000">对同一个基类的</font></span>多重继承中，子对象重复的问题(只保留一份)
 2. 对于这一份子对象：
	1. <font color="#c00000">完全虚继承路径只共享一个虚基类</font>，且<font color="#c00000">成员被值会被最父基类</font><span style="background:#fff88f"><font color="#c00000">初始化一次</font></span>。
	2. 非完全虚继承路径从非虚继承进行分岔，其中：
		1. 完全实路径遵守普通构造方式
		2. 完全虚路径遵守上述规则

#### 2.2.2.1 成员副本保留实例(虚继承基本目的) ^gnqqw0

考虑如下的菱形继承关系：

```CPP
struct A {
    int x;
};

struct B : public A { };
struct C : public A { };

struct D : public B, public C { };

// 访问 D.x
D.x = 0;       // 错误
d.B::A::x = 1; // 正确
d.C::A::x = 2; // 正确
```

那么如上述代码所示，<span style="background:#fff88f"><font color="#c00000">此时D中会有两个</font></span> `x` <span style="background:#fff88f"><font color="#c00000">成员</font></span>，且无法直接访问 `D.x` ，<font color="#c00000">必须按照</font> `d.B::A::x` <font color="#c00000">的方式访问</font>。

此时如果使用虚继承，则会将成员 `x` 合并到同一个成员中：

```CPP
struct A {
    int x;
};

struct B : virtual public A { };
struct C : virtual public A { };

// 如不考虑D的子类继承问题，则D这里无须再写 `virtual`
struct D : public B, public C { }; 

// 访问 D.x
D.x = 0;       // 正确, 且这三个本质是同一个成员
d.B::A::x = 1;
d.C::A::x = 2;
```

#### 2.2.2.2 子类构造实例 ^okzboq

```CPP
struct A {
    int x;
    A(int v) : x(v) { printf("A(%d), A.x=%d\n", v, x); }
};

struct B : virtual public A {
    B(int v) : A(v) { printf("B(%d), B.x=%d\n", v, x); }
};

struct C : virtual public A {
    C(int v) : A(v) { printf("C(%d), C.x=%d\n", v, x); }
};

struct D : public B, public C {
    D() : A(3), B(2), C(1) { printf("D(), D.x=%d\n", x); }
};

struct E: virtual public C, virtual public B {
	E() : A(3), B(2), C(1) { printf("E(), E.x=%d\n", x); }
};
```

当构造类 `D` 时，则：
1. 按照声明顺序构造所有虚基类：
	- 从左向右，从深到浅的遍历，则遍历顺序为： `A->B->C`
	- 而其中只有虚基类 `A` ，则：
		- 赋值 `A.x=3` 
		- 输出 `A(3), A.x=3`
2. 按照继承顺序从左到右构造非虚直接基类：
	- 顺序为 `B->C` ：
		1. 构造 `B` ：
			1. 由于共享一份 `A` ，且已构造，故跳过  `A` 的构造构造
			2. 执行并输出 `B(2), B.x=3`
		2. 构造 `C` :
			1. 由于共享一份 `A` ，且已构造，故跳过  `A` 的构造构造
			2. 执行并输出 `C(1), C.x=3`
3. 按声明顺序构造所有非静态成员变量：无
4. 执行并输出 `D(), D.x=3`

当构造类 `E` 时，则：
1. 按照声明顺序构造所有虚基类：
	- 从左向右，从深到浅的遍历，则遍历顺序为： `A->C->B`
	- 构造 `A` ：
		- 赋值 `A.x=3` 
		- 输出 `A(3), A.x=3`
	- 构造 `C` ：
		- 由于共享一份 `A` ，且已构造，故跳过  `A` 的构造构造
		- 输出 `C(1), C.x=3`
	- 构造 `B` ：
		- 由于共享一份 `A` ，且已构造，故跳过  `A` 的构造构造
		- 输出 `B(2), B.x=3`
2. 按照继承顺序从左到右构造非虚直接基类：无
3. 按声明顺序构造所有非静态成员变量：无
4. 执行并输出 `E(), E.x=3`

## 2.3 接口

在面相对象的程序设计中，接口可以理解为一个规范或约定。

在Java中，接口可通过如下方式定义：

```Java
public interface Animal {
	String getName();
	void setName(String name);
	void makeSound();
}
```

在上述的若干语言中的代码均定义了一个最基础的 `Animal` "规范"(即接口)，均定义有如下方法：
- 获取名字
- 设置名字
- 制造叫声

而在C++中并未提供类似于Java中直接给出的 `interface` 关键字，因此在C++中的接口通常使用抽象类实现。抽象类与虚函数、纯虚函数之间的关系如下：
- 包含虚函数的类可以是普通类
- 包含<font color="#c00000">纯虚函数</font>的类<span style="background:#fff88f"><font color="#c00000">一定是抽象类</font></span>
虚函数与纯虚函数可见章节[[面向对象的程序设计/面向对象的程序设计#^gcn6sq|虚函数与纯虚函数]]。

接口的demo如下：

```C++
class IAnimal {
public:
    // 纯虚函数，使 IAnimal 成为抽象类
    virtual std::string getName() const = 0; // 获取动物的名字
    virtual void setName(const std::string& name) = 0; // 设置动物的名字
    virtual void makeSound() = 0; // 发出声音

    // 虚析构函数，确保派生类的析构函数被调用
    virtual ~IAnimal() {}
};
```

## 2.4 多态

### 2.4.1 基本概念

`多态` (`Polymorphism`)是一个希腊词汇，从字面上理解为多种形态。
<span style="background:#fff88f"><font color="#c00000">该特性允许开发者使用相同的接口调用不同的基类方法</font></span>。
其最重要的两个要素为：
1. <font color="#c00000">接口的一致性</font>：通过相同的接口或抽象基类调用方法。
2. <font color="#c00000">行为的多样性</font>：在派生类中实现相同的接口方法，但具有不同的行为。

在上述的定义下，从语言理论上，多态通常有如下的分类：
1. 类型多态
	1. 参数多态：例如使用泛型，允许函数或数据类型在不同数据类型上操作而不必对每种数据类型编写单独的代码。
	2. 包含多态：又称为<span style="background:#fff88f"><u>子类型多态</u></span>。这种多态性依赖于继承机制，允许子类类型的对象被视为其父类类型的对象使用，同时保持自己的方法实现。它是动态多态的一种实现方式，主要通过虚函数来实现。
2. 接口多态：接口多态指通过接口的实现，不同的类可以以相同的方式被处理。这是面向对象编程中的核心概念之一，它强调实现特定接口的类必须提供接口声明的所有方法的实现。
3. 广义多态
	1. 函数重载
	2. 运算符重载
4. 协变与逆变
	1. 协变：允许一个方法<font color="#c00000">返回</font>比它在父类中声明的方法更具体的类型
	2. 逆变：允许一个方法<font color="#c00000">接收</font>比它在父类中声明的方法更一般的类型作为参数
而从多态解析的时间上进行分类，则有如下的类型：
1. 静态多态：在编译期间进行多态的解析。
2. 动态多态：在运行时进行多态的解析(通常依赖类中的指针)。

接下来将根据如下的C++代码对如上的若干分类进行讨论：

```CPP
#include <iostream>

// 基类
class Animal {
public:
    // 虚函数
    virtual void makeSound() {
        std::cout << "Some animal sound" << std::endl;
    }
    virtual ~Animal() {}  // 虚析构函数，确保删除派生类对象时，能正确调用派生类的析构函数
};

// 派生类 Dog
class Dog : public Animal {
public:
    void makeSound() override {
        std::cout << "Woof" << std::endl;
    }
};

// 派生类 Cat
class Cat : public Animal {
public:
    void makeSound() override {
        std::cout << "Meow" << std::endl;
    }
};

// 函数，接受 Animal 类型的引用
void perform(Animal &animal) {
    animal.makeSound();
}

int main() {
    Dog myDog;
    Cat myCat;

	myDog.makeSound();
	myCat.makeSound();

    perform(myDog);  // 输出 Woof
    perform(myCat);  // 输出 Meow

    return 0;
}
```

在上述代码中：
1. `Dog` 和 `Cat` 类继承了 `Animal` 类，并重写了 `makeSound` 方法，是<font color="#c00000">类型多态中的包含多态</font>。
2. `myDog.makeSound();` 和 `myCat.makeSound();` ：
	1. 在多态的语言理论上的分类来看是<font color="#c00000">接口多态</font>。
	2. 其多态的解析是在编译时进行的，从解析的时间上进行分类是<font color="#c00000">静态多态</font>。
3. `void perform(Animal &animal);` 、 `perform(myDog);` 以及 `perform(myCat);` ： 
	1. `perform` 方法允许接收比它在父类中声明的方法更一般的类型作为参数(即允许接收 `Dog` 和 `Cat` 类型)，属于<font color="#c00000">逆变</font>。
	2. 在其方法中，多态的解析是在运行时进行的，从解析的时间上进行分类是<font color="#c00000">动态多态</font>。

### 2.4.2 类型转换(子类转父类与父类转子类)

正如类的继承关系，通常父类是子类的子集。因此<font color="#c00000">子类转父类通常是自动转换的</font>，<font color="#c00000">该过程是多态</font>的一种特性。<font color="#c00000">这个过程叫做向上转型</font>。
而当父类转子类时，该方法通常需要强制类型转换。<font color="#c00000">而子类通常含有父类所不拥有的特性和方法，因此并不是所有的父类转子类都会成功</font>。通常来说，<span style="background:#fff88f"><font color="#c00000">该转换成功的前提是该父类事实上是子类隐式转换过来的，也就是说前提是这个父类本身就是这个子类</font></span>。<font color="#c00000">这个过程叫做向下转型</font>。

### 2.4.3 重载&重写

基本概念：
- <font color="#9bbb59">重载</font>(<font color="#9bbb59">Overloading</font>)：
	重载是指在同一个类中可以有多个同名的方法，但是这些方法的参数列表不同。这些方法通常被设计为相似的功能。
- <font color="#9bbb59">重写</font>(<font color="#9bbb59">Overriding</font>)：
	重写的基本释义为子类覆盖父类中的一个实现。
	重写允许子类重新定义继承自父类的一个方法，<font color="#c00000">重写的方法在子类中必须具有相同的方法名</font>、<font color="#c00000">参数列表和相同或协变的返回类型</font>。

### 2.4.4 虚函数与纯虚函数(CPP) ^gcn6sq

#### 2.4.4.1 虚函数与纯虚函数的定义方式

在C++中，虚函数与纯虚函数的<font color="#c00000">区别为</font><span style="background:#fff88f"><font color="#c00000">是否提供实现</font></span>，例如：

```CPP
class IAnimal {
public:
	// 虚函数，提供默认实现
	virtual ~IAnimal() {}
	
    // 纯虚函数，使用 `=0` 不提供实现
    virtual std::string getName() const = 0;
    virtual void setName(const std::string& name) = 0;
    virtual void makeSound() = 0;
};
```

且需要注意，在C++中：
- 虚函数与纯虚函数<span style="background:#fff88f"><font color="#c00000">只能作为</font></span><font color="#c00000">非静态的</font><span style="background:#fff88f"><font color="#c00000">成员函数</font></span>
- <font color="#c00000">构造函数不能是虚函数</font>
- <font color="#c00000">析构函数通常<u><b>必须</b></u>是虚函数</font>，考虑如下的场景：
	- 当 `delete` 一个指向子类对象的父类指针时，若父类的析构函数不是虚函数，则其只会调用父类的析构函数，而非子类的析构函数
