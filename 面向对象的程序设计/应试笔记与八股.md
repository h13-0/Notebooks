# 2 面向对象的三大基本特性 ^75e6h0

考查企业：
- 商汤科技 嵌入式

面向对象的三大基本特性为：
- 封装：将一组数据、方法捆绑到一起，封装为一个类。
- 继承：允许子类自动拥有父类的成员和方法，并在此基础上拓展和修改。
- 多态：同一个方法在不同的对象上执行时，表现出不同的行为。

# 3 面向对象的四大基本特性

很少考查，在三大基本特性上加入"抽象"特性即为四大基本特性：
- 抽象：将一类事物的共同特征提取出来，封装为类的过程即为抽象。
