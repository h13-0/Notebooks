# 2 内核头文件包制作与安装

内核头文件包指的是通过 `sudo apt install linux-headers-$(uname -r)` 得到的 `/lib/modules/$(shell uname -r)/build` 目录下的<font color="#c00000">专为外部模块构建裁剪过的</font>部分源代码(包含 `.c` 、 `.h` 等文件)。





其制作通常需要如下几个步骤：
1. 准备构建外部模块所需的头文件和生成文件：
```Shell
make prepare modules_prepare
```
2. 准备一个文件夹，用于接收构建出来的头文件包，并假设该文件包的路径为 `$ROOTFS` (如果有编译根文件系统，则直接选择根文件系统所在目录即可)
3. 传递参数并执行 `modules_install` 编译指令：
```shell
make INSTALL_MOD_PATH=$ROOTFS modules_install
```
4. 

随后按需使用即可。
