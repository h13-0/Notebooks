# 2 从boot.img中提取内核编译配置

对于裸文件系统镜像格式的镜像，其镜像大小与分区大小一致，可以选择直接挂载该 `boot.img` ：

```shell
sudo mount -o ro,loop boot.img /mnt/bootimg
```

挂载后检查挂载路径下是否拥有 `config-${version}` 即为编译时配置文件。

对于 `Android boot image` 格式的镜像，可以选择：

```shell
mkdir out && unpack_bootimg --boot_img boot.img --out out
```
