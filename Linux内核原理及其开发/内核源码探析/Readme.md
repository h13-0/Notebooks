#嵌入式 #Linux驱动开发 #操作系统

本笔记主要用于记录、汇总内核中各函数的功能、原理、调用栈等。

# 1 笔记规则

笔记规则：
- 以源文件分析为主，目录结构与源码结构保持一致
- 各被分析对象均使用一级标题，标题使用其名称，不使用完整签名
- 各被分析对象应当注明被分析的源码版本
- 各被分析对象及其标题不再编号，但是要按在源码中出现的顺序排列

# 2 分析模板

## 2.1 函数分析模板

函数分析模板：

```markdown
# 函数名

版本：`${linux内核版本号}` % 格式要求见注1
分析状态：✅/⌛ % ✅表示已分析完毕、⌛表示未分析完毕

函数签名： ``



```

注：
- 上述 `%` 表示注释，在实际笔记中无此项目
- 版本格式为 `${VERSION}.${PATCHLEVEL}.${SUBLEVEL}${EXTRAVERSION}` ，例如 `6.10.0-rc1`
