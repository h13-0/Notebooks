#嵌入式 #Linux驱动开发 #操作系统

本笔记主要用于记录、汇总内核中各函数的功能、原理、调用栈等。

# 1 笔记规则

笔记规则：
- 以源文件分析为主，目录结构与源码结构保持一致
- 各被分析对象均使用一级标题，标题使用其名称，不使用完整签名
- 各被分析对象应当注明被分析的源码版本
- 各被分析对象及其标题不再编号，但是要按在源码中出现的顺序排列
- 分析内容存放于被定义处，例如：
	- 若某函数定义于头文件，则在头文件对应分析笔记中进行分析
	- 若某函数定义于源文件，则在源文件对应分析笔记中进行分析
- 声明处应当引用存放于定义处的分析
