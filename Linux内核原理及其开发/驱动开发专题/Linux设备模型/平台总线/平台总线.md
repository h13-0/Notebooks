## 2.3 平台设备

### 2.3.1 平台设备的数据结构

```C
struct platform_device {
	const char	*name;
	int		id;
	bool		id_auto;
	struct device	dev;
	u64		platform_dma_mask;
	struct device_dma_parameters dma_parms;
	u32		num_resources;
	struct resource	*resource;

	const struct platform_device_id	*id_entry;
	/*
	 * Driver name to force a match.  Do not set directly, because core
	 * frees it.  Use driver_set_override() to set or clear it.
	 */
	const char *driver_override;

	/* MFD cell pointer */
	struct mfd_cell *mfd_cell;

	/* arch specific additions */
	struct pdev_archdata	archdata;
};
```

其成员：
- `const char *name` ：
	- 功能含义：设备名称标识符(可重复)
	- 维护方：
		- 通过设备树或ACPI进行配置，则在其初始化时设置
		- 对于动态加载的虚拟设备，驱动需要在内核模块中<font color="#c00000">设备注册前设置</font>
- `int id` ：
	- 功能含义：设备实例ID，用于区分同名设备
	- 维护方：驱动可指定ID类型，内核(总线)在注册时自动分配。驱动可设置的数值有：
		- `PLATFORM_DEVID_AUTO` ：请求内核自动分配
		- `PLATFORM_DEVID_NONE` ：将该设备注册为单例设备
- `bool id_auto` ：
	- 功能含义：标记ID是否为自动分配
	- 维护方：内核自动维护，驱动只读访问
- `struct device dev` ：
	- 功能含义：内嵌的标准设备
	- 维护方：驱动负责配置基本字段( `.parent` 、 `.release` )
- `u64 platform_dma_mask` :
	- 功能含义：设备特定的DMA掩码，优先级比 `dev.dma_mask` 高：
		- 若 `platform_dma_mask` 非零，则使用 `platform_dma_mask`
		- 否则使用 `dev.dma_mask` 
	- 维护方：驱动初始化前按需设置
- `struct device_dma_parameters dma_parms` ：
	- 功能含义：DMA传输参数
- `u32 num_resources` ：
	- 功能含义：设备资源指针的数组大小(即下一成员指向的资源数量)
	- 维护方：驱动必须配置
- `struct resource *resource` ：
	- 功能含义：描述设备所占用的硬件资源，如I/O内存地址范围、中断号、DMA通道等
	- 维护方：驱动静态定义或设备树解析
- `const struct platform_device_id *id_entry` ：
	- 功能含义：

- `const char *driver_override` ：
	- 功能含义：强制绑定的指定驱动
	- 维护方：用户通过 `sysfs` 等方式强制设置，随后内核维护，驱动禁止直接修改
- `struct mfd_cell *mfd_cell` ：
	- 功能含义：指向的MFD单元
	- 维护方：MFD驱动初始化，由MFD子系统管理
- `struct pdev_archdata archdata` ：
	- 功能含义：体系结构的特定数据

/**
 * platform_device_register - add a platform-level device
 * @pdev: platform device we're adding
 *
 * NOTE: _Never_ directly free @pdev after calling this function, even if it
 * returned an error! Always use platform_device_put() to give up the
 * reference initialised in this function instead.
 */
int platform_device_register(struct platform_device *pdev);
