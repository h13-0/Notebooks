# 2 基本概念

## 2.1 项目空间

Git的项目空间主要分为如下三个基本概念：
- 工作区()：
	- 正常可直接编辑的目录文件
- <font color="#9bbb59">暂存区</font>(<font color="#9bbb59">Staging</font>)：
	- 从工作区中选出的，准备进行提交的那部分改动
		- 改动是以行为单位的，其会自动对修改行分块(`hunk`)，分出来的块可再次手动细分
- 本地仓库：
	- 
	- 即 `.git` 文件夹下的Git仓库数据

上述三个区域的流动及其方法为：
- `工作区->暂存区` ：`git add ${file}`
- `暂存区->本地仓库` ： `git commit -m ${comment}`
