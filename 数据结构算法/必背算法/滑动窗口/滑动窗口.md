# 滑动窗口经典题目

[[数据结构算法/LeetCode/LeetCode题目汇总#3 无重复字符的最长子串|LeetCode 3]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#3 无重复字符的最长子串]]

```CPP
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        auto start = s.begin();
        auto end = start;
        int length = 0;
        bool exist[256] = { 0 };
        while(end < s.end()) {
            if(exist[*end] == false) {
                // 未重复，向前延伸
                exist[*end] = true;
                end ++;
            } else {
                // 与中间元素重复，窗口缩减到首个重复项
                length = max(int(end - start), length);
                while(start < end && *start != *end) {
                    exist[*start] = false;
                    start ++;
                }
                // 窗口前移，准备在下一循环中判定
                start ++;
                end ++;
            }
        }
        return max(int(end - start), length);
    }
};
```
