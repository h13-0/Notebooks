# 2 双指针法经典题目

[[数据结构算法/LeetCode/LeetCode题目汇总#283 移动零|LeetCode 283 移动零]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#283 移动零]]

思路：
- 可以把任务想象为：
	- 一个一维空间中，有许多"气泡"和"物体"
	- 现在需要把"气泡"排出，并保持"物体"之间原始顺序
- 那么从左向右将空间压实即可：
	1. 左侧一个指针指向第一个"气泡"
	2. 右侧一个指针指向"气泡"后的第一个"物体"
	3. 然后把"物体"压缩到左侧的"气泡"处
	4. <font color="#c00000">右侧的指针无需再从左侧指针开始遍历</font>，继续向下走即可，这样也可以省去清空右侧"原物体"空间的操作

题解：

```CPP
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        auto left = nums.begin();
        // 从 left 的位置执行后续遍历，节约left判0的边界条件
        auto right = left;
        while(right < nums.end()) {
            if(*right) {
                swap(*left, *right);
                left ++;
            }
            right ++;
        }
    }
};
```


# 3 双指针法变体

## 3.1 三指针

[[数据结构算法/LeetCode/LeetCode题目汇总#15 三数之和|LeetCode 15 三数之和]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#15 三数之和]]

思路：
1. 本题题目中给定 `i`、`j`、`k` 三个指针，此时我们可以<font color="#c00000">在依次遍历一个指针的情况下</font>，<font color="#c00000">将剩下的两个指针看作双指针问题</font>
2. 其要求：
	1. <font color="#c00000">三个指针指向的元素不能重复</font>
	2. <font color="#c00000">三数之和为零</font>
	3. <font color="#c00000">三元组不能重复</font>
3. 那么可以考虑：
	1. 三数之和为零，那么则有：`nums[j] + nums[k] = - nums[i]` 
	2. 此时可以将 `i` 指针从 `nums.begin()` 遍历到 `nums.end()` ，并找到 `j`、`k`，满足要求 `nums[j] + nums[k] = - nums[i]` ：
		1. 可以将原数组进行排序，从而可以实现"双指针"遍历
		2. 左右指针依次向中逼近，从而找到满足要求<font color="#c00000">所有</font>的 `j` 和 `k`
