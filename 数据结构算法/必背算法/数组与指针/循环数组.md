# 2 循环采样

考虑长度为 $n$ 的一个<font color="#c00000">循环数组</font>，我们以 $k$ 为间距对该数组进行<font color="#c00000">循环采样</font>，直到重复，即对于如下的数组：

```text
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐ 
│  0  │  1  │  2  │  3  │  4  │  5  │  6  │  7  │ 
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘ 
```

以 $6$ 为间距对其进行循环采样，则有如下的采样序列：
- `0->6->4->2->0` ：直到采样到 `0` ，即最终循环为 `0->6->4->2`

<font color="#c00000">那么则有如下的数学结论</font>：
1. <font color="#c00000">每次循环经过的采样点数为</font> $\displaystyle\frac{n}{gcd(k, n)}$ 
2. <font color="#c00000">循环内采样点间距为</font> $gcd(k, n)$
3. 只需要<span style="background:#fff88f"><font color="#c00000"><u>连续</u></font></span>(即起点相邻) $gcd(k, n)$ <font color="#c00000">个循环采样</font>即可<span style="background:#fff88f"><font color="#c00000">无重复地</font></span><font color="#c00000">遍历数组</font>
