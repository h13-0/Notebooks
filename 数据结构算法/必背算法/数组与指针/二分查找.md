# 2 实现与边界条件

[[数据结构算法/LeetCode/LeetCode题目汇总#35 搜索插入位置|LeetCode 35]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#35 搜索插入位置]]

二分法搜索的关键点是边界条件的控制，通常来说边界条件有如下两种：
- 左闭右闭：`[left, right]`
	- 循环条件：`left<=right`
	- 中指针：`(left+right)/2` (向下取整，不考虑溢出)
- 左闭右开：`[left, right)`
	- 循环条件：`left<right`
	- 中指针：`(left+right)/2` (向下取整，不考虑溢出)
