# 2 基本概念

给定一个数组 `nums[n]` ，假设 `pre[i]` 是数组 `nums` 中从下标 `0` 到 `i` 的元素之和，那么 `pre[i]` 即叫作数组 `nums[n]` 的<font color="#9bbb59">前缀和</font>：
$$
pre[i]=\sum_{k=0}^{i}{nums[k]}
$$

其用途有：
1. <font color="#c00000">快速大批量求解数组</font> `nums` <font color="#c00000">的切片的和</font> $Sum(i, j), j\geq i$：
$$
Sum(i, j) = pre[j] - pre[i-1]
$$
	- 注意：
		- <font color="#c00000">求解切片和时</font>，<span style="background:#fff88f"><font color="#c00000">必须保证</font></span> $j\geq i$ 
		- 因此求解切片和时，通常同时构造和使用前缀和求解

# 3 例题

## 3.1 快速求解大批量(遍历)数组切片和

[[数据结构算法/LeetCode/LeetCode题目汇总#560 和为K的子数组|LeetCode 560]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#560 和为K的子数组]]

注意：
1. <font color="#c00000">数组中元素可能为负值</font>
2. <font color="#c00000">数组目标和k可能为负值</font>
3. <font color="#c00000">求解切片和时</font>，<span style="background:#fff88f"><font color="#c00000">必须保证</font></span> $j\geq i$ ，<font color="#c00000">故选择同时构造和使用前缀和求解</font>

```CPP
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        int times = 0;
		
        // 前缀和value, 出现次数times
        // 需要提前插入一个 0:0 , 以统计 k=[0, i] 的情况
        unordered_map<int, int> prefix_map{ { 0, 1} };
		
        // 构造前缀和，同时利用已有前缀和求解，以保证切片和符号的正确性
        int sum = 0;
        for(int i = 0; i < nums.size(); i++) {
            sum += nums[i];
			
            // 利用已有前缀和求解
            // 令 target 满足 k=sum - target
            int target = sum - k;
            if(prefix_map.contains(target)) {
                times += prefix_map[target];
            }
			
            // 插入新的前缀和
            if(prefix_map.contains(sum)) {
                prefix_map[sum] ++;
            } else {
                prefix_map[sum] = 1;
            }
        }
		
        return times;
    }
};
```

## 3.2 最大子数组和

[[数据结构算法/LeetCode/LeetCode题目汇总#53 最大子数组和|LeetCode 53]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#53 最大子数组和]]

注意：
1. 子数组必须包含至少一个元素
2. 同样<font color="#c00000">需要选择同时构造和使用前缀和</font>
3. 计算当前最大前缀和时，应当使用"<font color="#c00000">当前前缀和-除开当前前缀和以外的最小前缀和</font>"进行计算。

```CPP
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        // 当前前缀和
        int sum = 0;
        // 除开当前前缀和以外的最小前缀和
        int min_sum = 0;
        // 前缀和的最大最小值
        int result = nums[0];
        for(auto i = nums.begin(); i < nums.end(); i++) {
            min_sum = min(sum, min_sum);
            sum += *i;
            result = max(result, sum - min_sum);
        }
        return result;
    }
};
```
