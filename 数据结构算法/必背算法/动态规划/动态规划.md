# 2 动态规划概述

动态规划，`Dynamic Programming`，简称<font color="#9bbb59">DP</font>，是一种通过把原问题分解为相对简单的子问题的方式求解复杂问题的方法。
其核心特性为：
- 大事化小
- 记忆结果
- 不再重复

动态规划可以解决的问题通常具备如下特征：
1. 重叠子问题：求解过程中，遇到了很多个重复的小问题
	- 例如：求解斐波那契数列 $F(n)=F(n-1)+F(n-2), F(0)=0, F(1)=1$ 
	- 那么：在求解的过程中，将重复 $n-k$ 次求解 $F(k)$ 
2. 最优子结构：原问题的最优解可以通过子问题的最优解推导出来。
	- 例如：求从北京坐火车去深圳的最短时间
	- 假设我们已知从北京去深圳必经过武汉，那么：
		- "北京->深圳的最短时间"="北京->武汉的最短时间"+"武汉->深圳的最短时间"

动态规划问题在求解时有如下的三部曲：
1. <span style="background:#fff88f"><font color="#c00000">定义状态</font></span>：定义数组，并明确数组中元素的含义
	- 以斐波那契数列为例，数组 `dp[n]` 就表示斐波那契数列中第 `n` 的元素的值
	- 以[[数据结构算法/必背算法/动态规划/动态规划#^5o8m54|爬楼梯]]为例，数组 `dp[n]` 就表示爬到第 `n` 个台阶的方法数量
2. <span style="background:#fff88f"><font color="#c00000">定义状态转移方程</font></span>：<font color="#c00000">找到</font> `dp[i]` <font color="#c00000">和之前状态之间的联系</font>
	- 以斐波那契数列为例，状态转移方程即为其定义 $F(n)=F(n-1)+F(n-2)$ 
	- 以[[数据结构算法/必背算法/动态规划/动态规划#^5o8m54|爬楼梯]]为例，其状态转移方程也为 $F(n)=F(n-1)+F(n-2)$ 
3. <span style="background:#fff88f"><font color="#c00000">初始化</font></span>：为最基础最简单的情况进行求解和赋值(需要满足状态转移方程的启动条件)
	- 以斐波那契数列为例，初始值即为 $F(0)=0, F(1)=1$ 
	- 以[[数据结构算法/必背算法/动态规划/动态规划#^5o8m54|爬楼梯]]为例，<font color="#c00000">其初始值为</font> $F(1)=1, F(2)=2$

[[数据结构算法/LeetCode/LeetCode题目汇总#70 爬楼梯|LeetCode 70]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#70 爬楼梯]]

经过动态规划三部曲的分析，不难得出爬楼梯问题类似于求斐波那契数列，只是初始值不一样，其值也与斐波那契数列之间有一个错位。

```CPP
class Solution {
public:
    int climbStairs(int n) {
        // 定义数组 methods[n] , methods[i] 为 i+1 个台阶时的方法数量
        // 初始化 methods[0] = 1, methods[1] = 2
        vector<int> methods = { 1 , 2 };
        methods.reserve(n);

        for(int i = 2; i < n; i++) {
            // 状态转移方程
            methods[i] = methods[i - 1] + methods[i - 2];
        }
        return methods[n - 1];
    }
};
```

## 3.3 打家劫舍

[[数据结构算法/LeetCode/LeetCode题目汇总#198 打家劫舍|LeetCode 198]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#198 打家劫舍]]

例如给定 `cash = [2,7,9,3,1]` 的数组，我们先关注于：
- 只劫第一家时：
	- 明显地，最大窃取金额即为 `cash[0]`
- 考虑劫前两家时：
	- 最大窃取金额为 `max(cash[0], cash[1])`
- 考虑劫第三家时：
	- <font color="#c00000">此时则要分两种情况考虑</font>：
		1. 先劫取 `cash[2]` ，随后再劫取 `cash[0]`
		2. 先劫取 `cash[1]` 
- 考虑劫前四家时：
	- 此时则要考虑：
		1. 先劫取 `cash[4]` ，随后考虑这两种方案中的最大值：
			1. `cash[2]` 和 `cash[0]` 
			2. `cash[1]`
		2. 先劫取 `cash[3]` ，随后劫取 `cash[1]`
	- <span style="background:#fff88f"><font color="#c00000">此时应当注意到</font></span>：
		- 截取第 $n$ 家时，<span style="background:#fff88f"><font color="#c00000">最大收入等价于</font></span>：
			- 第 $n$ 家和前 $n-2$ 家最大劫取收入
			- 前 $n-1$ 家最大劫取收入
		- <font color="#c00000">的最大值</font>

可得状态转移方程：
$$
max\_stolen(n)=max(max_stolen(n-1), max_stolen(n-2) + cash[n]), n>=2
$$

即可得动态规划实现：

```CPP
class Solution {
public:
    int rob(vector<int>& nums) {
        // stolen[i] 表示劫取前 i 家的最大收入, 0 <= i < nums.size
        vector<int> stolen(nums.size(), 0);

        // 设置初始值
        stolen[0] = nums[0];
        if(nums.size() >= 2) {
            stolen[1] = max(nums[0], nums[1]);
        }

        for(int i = 2; i < nums.size(); i++) {
            stolen[i] = max(stolen[i - 1], stolen[i - 2] + nums[i]);
        }
        return stolen[stolen.size() - 1];
    }
};
```

## 3.4 背包问题

背包问题假设每个资源均有如下的两个要素：
- 重量
- 价值
而该问题就是指在背包容量有限的情况下，在背包中装入最有价值的资源。其可以被分为如下几个大类：

| **背包类型**  | **核心特点**  | **决策逻辑**                | **现实类比**          |
| --------- | --------- | ----------------------- | ----------------- |
| **0/1背包** | 每样仅 $1$ 件 | 拿/不拿                    | 选课(这门课要么修，要么不修)   |
| **完全背包**  | 每样无限件     | 拿 $1, 2, ..., \infty$ 件 | 买邮票(同一种邮票可以买很多张)  |
| **多重背包**  | 每样限 $k$ 件 | 拿 $1, 2, ..., k$ 件      | 促销限购(每人限购5瓶)      |
| **分组背包**  | 组内互斥      | 组内任选 $1$ 件或不选           | 搭配套餐(饮料选一种，主食选一种) |
