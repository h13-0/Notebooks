# 2 动态规划概述

动态规划，`Dynamic Programming`，简称<font color="#9bbb59">DP</font>，是一种通过把原问题分解为相对简单的子问题的方式求解复杂问题的方法。
其核心特性为：
- 大事化小
- 记忆结果
- 不再重复

动态规划可以解决的问题通常具备如下特征：
1. 重叠子问题：求解过程中，遇到了很多个重复的小问题
	- 例如：求解斐波那契数列 $F(n)=F(n-1)+F(n-2), F(0)=0, F(1)=1$ 
	- 那么：在求解的过程中，将重复 $n-k$ 次求解 $F(k)$ 
2. 最优子结构：原问题的最优解可以通过子问题的最优解推导出来。
	- 例如：求从北京坐火车去深圳的最短时间
	- 假设我们已知从北京去深圳必经过武汉，那么：
		- "北京->深圳的最短时间"="北京->武汉的最短时间"+"武汉->深圳的最短时间"

动态规划问题在求解时有如下的三部曲：
1. <span style="background:#fff88f"><font color="#c00000">定义状态</font></span>：定义数组，并明确数组中元素的含义
	- 以斐波那契数列为例，数组 `dp[n]` 就表示斐波那契数列中第 `n` 的元素的值
	- 以[[数据结构算法/必背算法/动态规划/动态规划#^5o8m54|爬楼梯]]为例，数组 `dp[n]` 就表示爬到第 `n` 个台阶的方法数量
2. <span style="background:#fff88f"><font color="#c00000">定义状态转移方程</font></span>：<font color="#c00000">找到</font> `dp[i]` <font color="#c00000">和之前状态之间的联系</font>
	- 以斐波那契数列为例，状态转移方程即为其定义 $F(n)=F(n-1)+F(n-2)$ 
	- 以[[数据结构算法/必背算法/动态规划/动态规划#^5o8m54|爬楼梯]]为例，其状态转移方程也为 $F(n)=F(n-1)+F(n-2)$ 
3. <span style="background:#fff88f"><font color="#c00000">初始化</font></span>：为最基础最简单的情况进行求解和赋值(需要满足状态转移方程的启动条件)
	- 以斐波那契数列为例，初始值即为 $F(0)=0, F(1)=1$ 
	- 以[[数据结构算法/必背算法/动态规划/动态规划#^5o8m54|爬楼梯]]为例，<font color="#c00000">其初始值为</font> $F(1)=1, F(2)=2$

## 3.2 爬楼梯 ^5o8m54

[[数据结构算法/LeetCode/LeetCode题目汇总#70 爬楼梯|LeetCode 70]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#70 爬楼梯]]

经过动态规划三部曲的分析，不难得出爬楼梯问题类似于求斐波那契数列，只是初始值不一样，其值也与斐波那契数列之间有一个错位。

```CPP
class Solution {
public:
    int climbStairs(int n) {
        // 定义数组 methods[n] , methods[i] 为 i+1 个台阶时的方法数量
        // 初始化 methods[0] = 1, methods[1] = 2
        vector<int> methods = { 1 , 2 };
        methods.reserve(n);

        for(int i = 2; i < n; i++) {
            // 状态转移方程
            methods[i] = methods[i - 1] + methods[i - 2];
        }
        return methods[n - 1];
    }
};
```

## 3.3 打家劫舍

[[数据结构算法/LeetCode/LeetCode题目汇总#198 打家劫舍|LeetCode 198]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#198 打家劫舍]]

例如给定 `cash = [2,7,9,3,1]` 的数组，我们先关注于：
- 只劫第一家时：
	- 明显地，最大窃取金额即为 `cash[0]`
- 考虑劫前两家时：
	- 最大窃取金额为 `max(cash[0], cash[1])`
- 考虑劫第三家时：
	- <font color="#c00000">此时则要分两种情况考虑</font>：
		1. 先劫取 `cash[2]` ，随后再劫取 `cash[0]`
		2. 先劫取 `cash[1]` 
- 考虑劫前四家时：
	- 此时则要考虑：
		1. 先劫取 `cash[4]` ，随后考虑这两种方案中的最大值：
			1. `cash[2]` 和 `cash[0]` 
			2. `cash[1]`
		2. 先劫取 `cash[3]` ，随后劫取 `cash[1]`
	- <span style="background:#fff88f"><font color="#c00000">此时应当注意到</font></span>：
		- 截取第 $n$ 家时，<span style="background:#fff88f"><font color="#c00000">最大收入等价于</font></span>：
			- 第 $n$ 家和前 $n-2$ 家最大劫取收入
			- 前 $n-1$ 家最大劫取收入
		- <font color="#c00000">的最大值</font>

可得状态转移方程：
$$
max\_stolen(n)=max(max_stolen(n-1), max_stolen(n-2) + cash[n]), n>=2
$$

即可得动态规划实现：

```CPP
class Solution {
public:
    int rob(vector<int>& nums) {
        // stolen[i] 表示劫取前 i 家的最大收入, 0 <= i < nums.size
        vector<int> stolen(nums.size(), 0);

        // 设置初始值
        stolen[0] = nums[0];
        if(nums.size() >= 2) {
            stolen[1] = max(nums[0], nums[1]);
        }

        for(int i = 2; i < nums.size(); i++) {
            stolen[i] = max(stolen[i - 1], stolen[i - 2] + nums[i]);
        }
        return stolen[stolen.size() - 1];
    }
};
```

## 3.4 背包问题

背包问题假设每个资源均有如下的两个要素：
- 重量
- 价值
而该问题就是指在背包容量有限的情况下，在背包中装入最有价值的资源。其可以被分为如下几个大类：

| **背包类型**  | **核心特点**  | **决策逻辑**                | **现实类比**          |
| --------- | --------- | ----------------------- | ----------------- |
| **0/1背包** | 每样仅 $1$ 件 | 拿/不拿                    | 选课(这门课要么修，要么不修)   |
| **完全背包**  | 每样无限件     | 拿 $1, 2, ..., \infty$ 件 | 买邮票(同一种邮票可以买很多张)  |
| **多重背包**  | 每样限 $k$ 件 | 拿 $1, 2, ..., k$ 件      | 促销限购(每人限购5瓶)      |
| **分组背包**  | 组内互斥      | 组内任选 $1$ 件或不选           | 搭配套餐(饮料选一种，主食选一种) |

### 3.4.1 0/1背包问题

[[数据结构算法/LeetCode/LeetCode题目汇总#2915 和为目标值的最长子序列的长度|LeetCode 2915]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#2915 和为目标值的最长子序列的长度]]

在传统的动态规划问题中，数组 `dp[i]` 中，自变量 `i` 表示问题的规模，例如爬楼梯问题中的楼梯数、打家劫舍问题中的家庭数等。

而在背包问题中，需要同时考虑：
- 物品规模：当前考虑到第几个物品了。即背包容量固定时，物品选择子问题维度。
- 背包容量：当前考虑到的最大背包容量。即背包容量子问题维度。
两个维度

<font color="#c00000">因此则有三部曲</font>：
- 数组 `dp[i][j]` 表示：表示前 $i$ 个物品组合中，背包容量<span style="background:#fff88f">不超过</span>/<span style="background:#fff88f">等于</span> $j$ 的情况下的<span style="background:#fff88f"><font color="#c00000"><b>最大价值</b></font></span>：
$$
dp[i][j]=max\_value
$$
- 状态转移方程：即考虑如下两种选择之间的最大值
	- <span style="background:#fff88f"><font color="#c00000">不拿</font></span>：不拿物品 $i$ 时，<font color="#c00000">对应价值</font> `dp[i - 1][j]`
	- <span style="background:#fff88f"><font color="#c00000">拿</font></span>：当考虑拿物品 $i$ 时，<font color="#c00000">对应价值</font> `v[i] + dp[i - 1][j - w[i]]`
	<font color="#c00000">之间的最大值</font>，即：
$$
max(拿, 不拿)
$$
- 初始化条件：
	- 由于状态转移时，<font color="#c00000">需要考虑是否可以凑出当前重量</font>，而非只考虑当前重量的解数，<font color="#c00000">因此数组初始化的值通常设置为</font> `-1`

注意：
1. 数组 `dp[i][j]` 表示是背包容量<font color="#c00000"><u>不超过</u></font> $j$ 还是<font color="#c00000"><u>等于</u></font> $j$ <span style="background:#fff88f"><font color="#c00000">取决于具体的题目要求</font></span>，<span style="background:#fff88f"><font color="#c00000">即是否要求背包装满</font></span>
2. 为了方便优化为一维数组形式，<font color="#c00000">通常要先遍历物品</font>，<font color="#c00000">再遍历容量</font>

#### 3.4.1.1 二维数组形式

对于本题，则有：
- `dp[i][j]` 表示前 $i$ 个物品组合中，背包容量<span style="background:#fff88f"><font color="#c00000"><b><u>等于</u></b></font></span> $j$ 时的最大价值
- `v[i] = 1`
- `w[i] = nums[i]`

```CPP
class Solution {
public:
    int lengthOfLongestSubsequence(vector<int>& nums, int target) {
        // 初始化dp数组，dp[i][j] 表示前 i 个物品中，背包容量等于 j 时的最大价值
        // 初始值为-1，表示无合法组合
        vector<vector<int>> dp(nums.size() + 1, vector<int>(target + 1, -1));

        // 设置初始化条件：当容量为0时，组合为0
        for(int i = 0; i <= nums.size(); i++) {
            dp[i][0] = 0;
        }

        // i 为物品
        for(int i = 1; i <= nums.size(); i++) {
            // j 为容量
            for(int j = 1; j <= target; j++) {
                // 定义 weight 和 val
                int weight = 1;
                int val = nums[i - 1];

                // 判定是否可拿条件：
                // 1. 背包可容下当前物品i，即：j >= val
                // 2. 背包容量为 j - i 时有解，即：dp[i - 1][j - val] != -1
                if(j >= val && dp[i - 1][j - val] >= 0) {
                    // dp = max(不拿, 拿)
                    dp[i][j] = max(
                        dp[i - 1][j],                // 不拿
                        dp[i - 1][j - val] + weight  // 拿
                    );
                } else {
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }
        
        // dp[i][j] 表示前 i 个物品中，背包容量等于 j 时的最大价值
        // 因此直接返回 dp[nums.size()][target] 即可
        return dp[nums.size()][target];
    }
};
```

当然，上述 `24-32` 行中的"判定是否可拿->拿/不拿->不拿"的逻辑可以合并和精简，不过此处省略。

#### 3.4.1.2 一维数组形式

明显地，在上述先遍历物品，再遍历容量的状态转移中，由于其 `dp` 数组只依赖于上一个物品的 `dp` 状态(即只依赖 `dp[i - 1]` )，因此其可以合并为一维数组的形式，但是需要注意：
1. 在对固定的 `i` 、`j` 遍历时，<span style="background:#fff88f"><font color="#c00000">其会依赖于比当前</font></span> `j` <span style="background:#fff88f"><font color="#c00000">更小的</font></span> `j - val` ：
	- `dp[i - 1][j - val]` 
2. 但是当我们保持原有逻辑从前向后遍历 `j` 时，<font color="#c00000">会导致当前</font> `j` <font color="#c00000">使用已经被更新的当前轮次的</font> `j - val` ，<font color="#c00000">从而导致逻辑错误</font>(变成[[数据结构算法/必背算法/动态规划/动态规划#^5mw6t9|完全背包问题]]) ^5kjk6n
3. 因此可以将 `j` 改为<span style="background:#fff88f"><font color="#c00000">从后向前遍历</font></span>，以避免逻辑错误


```CPP
class Solution {
public:
    int lengthOfLongestSubsequence(vector<int>& nums, int target) {
        // 一维数组形式：dp[j] 表示容量为 j 的情况下，上一轮物品 i 的 dp 表
        vector<int> dp(target + 1, -1);

        // 设置初始化条件：当容量为0时，组合为0
        dp[0] = 0;

        // i 为物品
        for(int i = 1; i <= nums.size(); i++) {
            // j 为容量，需要倒序遍历
            for(int j = target; j > 0; j--) {
                // 定义 weight 和 val
                int weight = 1;
                int val = nums[i - 1];

                // 无论i、j为何值，其一定可以不拿，则：dp[j] = dp[j]
                // dp[j] = dp[j];

                // 判定是否可拿条件：
                // 1. 背包可容下当前物品i，即：j >= val
                // 2. 背包容量为 j - i 时有解，即：[j - val] != -1
                if(j >= val && dp[j - val] >= 0) {
                    // dp = max(不拿, 拿)
                    dp[j] = max(
                        dp[j],                // 不拿
                        dp[j - val] + weight  // 拿
                    );
                }
            }
        }

        // dp[i][j] 表示前 i 个物品中，背包容量等于 j 时的最大价值
        // 因此直接返回 dp[nums.size()][target] 即可
        return dp[target];
    }
};
```
