# 2 二叉树的遍历

## 2.1 先序、中序、后序遍历

<span style="background:#fff88f"><font color="#c00000">二叉树的先序、中序、后续遍历遍历中的x序是指根节点被访问的顺序</font></span>，即：
- 先序遍历访问顺序：根节点->左子树->右子树(通常为先左后右，下同)
- 中序遍历访问顺序：左子树->根节点->右子树
- 后序遍历访问顺序：左子树->右子树->根节点
通常来说，先序、中序、后序遍历都依靠递归或迭代的思想进行：

| 区别    | <center>递归</center> | <center>迭代</center> |
| ----- | ------------------- | ------------------- |
| 空间复杂度 | $O(h)$              | $O(h)$              |
| 内存位置  | 栈内存                 | 堆内存                 |
| 风险    | 深度太大会导致栈溢出          | 只要内存足够，不会溢出         |
| 额外开销  | 较大                  | 较小                  |

在性能不太敏感时，可以使用较为简单的递归写法。性能敏感时需要使用迭代写法。

### 2.1.1 递归实现

```CPP
class Solution {
public:
    TreeNode* traverseTree(TreeNode* root) {
    	// 终止条件
        if(root == nullptr) {
            return root;
        }
		
		// 先后遍历左右子树
        traverseTree(root->left);
        traverseTree(root->right);
        // 处理根节点的顺序对应遍历顺序
		task(root)
        return root;
    }
};
```

## 3.1 对称二叉树

[[数据结构算法/LeetCode/LeetCode题目汇总#101 对称二叉树|对称二叉树]]：
![[数据结构算法/LeetCode/LeetCode题目汇总#101 对称二叉树]]

递归实现：

```CPP
class Solution {
public:
    // 检测来自于左侧和右侧的镜像节点对应的子树是否镜像
    bool check(TreeNode* left, TreeNode* right) {
        // 当左右均为空时返回 true
        if(left == nullptr && right == nullptr) return true;
        // 当左右节点只有一个为空时返回 false
        if(left == nullptr || right == nullptr) return false;
        // 随后左右节点必定均不为空，判值相等即可
        if(left->val != right->val) return false;
        // 递归判定左右子树
        return check(left->left, right->right) && check(left->right, right->left);
    }
	
    bool isSymmetric(TreeNode* root) {
        return check(root->left, root->right);
    }
};
```

迭代实现：

```CPP
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        deque<TreeNode*> left_deque = { root->left };
        deque<TreeNode*> right_deque = { root->right };

        while(!left_deque.empty() && !right_deque.empty()) {
            // 取队头
            auto left = left_deque.front();
            auto right = right_deque.front();
            left_deque.pop_front();
            right_deque.pop_front();
			
            // 1. 判节点是否均空
            if(left == nullptr && right == nullptr) continue;
            // 2. 判节点是否含空
            if(left == nullptr || right == nullptr) return false;
            // 3. 此时节点均非空，进行值判定
            if(left->val != right->val) return false;
            // 4. 按镜像顺序，分别将子节点加入队列进行迭代
            left_deque.push_back(left->left);
            left_deque.push_back(left->right);
            right_deque.push_back(right->right);
            right_deque.push_back(right->left);
        }
        return true;
    }
};
```
